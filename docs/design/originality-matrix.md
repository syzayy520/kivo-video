# 全站「原创 / 复刻」决策矩阵

> 2026-11-17 ｜ 原则：**能做得比 rex 好就原创，不能就 1:1 复刻**。
> 结构可对齐（用户习惯），但图标/字标/渐变/组件形态/动效必须用 kivo 自有语言，避免抄袭指控。
> 已复刻并对齐的部分不回退，只做「能明确更好」的增量。

## 0. 判定标准（三项全过才原创）

1. **有能力支撑**：kivo 有 rex 没有的产品能力（4K/HDR/10bit 硬解、多实例、SMB/Emby/网盘、本地+远程混一）。
2. **用户可感知**：同屏并排能一眼看出「这个更好」，不是自我感觉良好。
3. **可举证差异**：信息架构或组件形态与 rex 明显不同，不靠换色伪装原创。

三项缺一 → 复刻。

## 1. 逐页结论

| 页面 | rex 做法 | kivo 能否更好 | 结论 | 差异化落点 |
| --- | --- | --- | --- | --- |
| **底部导航** | 4 Tab + 独立搜索圆钮，白胶囊选中 | 结构更好不了（习惯已成型） | **复刻结构** | 图标用自有 glyph；头像位放真实头像（D-4） |
| **发现页 · Hero** | 轮播大图 + 分页点 + 评分徽章 | 能：影院幕布叙事（暗场光晕 + 一句"今晚看什么"） | **原创（Hero 层）** | 幕布光晕、片单式分页点、可点整卡 |
| **发现页 · 各横滑区** | 2:3 / 16:9 横滑卡 | 不能（结构就是最优解） | **复刻** | 仅令牌/圆角自有 |
| **热门人物** | 圆头像 + 姓名 + 演员 | 能微幅：加"代表作"一行 | **微原创** | 副标题显示代表作而非统一"演员" |
| **播出平台** | 品牌字标 + 右侧剧集拼贴（HBO 深底） | 能：字标 + 品牌底 + 拼贴，避开 TMDB logo 黑底 | **已原创** | 品牌色映射（Netflix/HBO/Disney/hulu/iQIYI/腾讯…） |
| **分类浏览** | 两列 3:1，左叠层海报 + 右文字 | 结构不能更好 | **复刻结构** | 叠层图尺寸自有 |
| **高分剧集** | 5 列纯海报 + 居中标题 | 不能 | **复刻** | — |
| **电影公司** | 2 列 2.2:1，剧照底 + 白 logo | 结构不能更好 | **复刻结构** | 洗色与 logo 处理自有 |
| **资源库** | 网格卡 + 计数 + 分组 + 五段式添加 | 能：加「源健康度」（延迟/容量/最近失败） | **原创增量** | 卡片右侧健康点 + 详情；复用 rex 的添加流程结构 |
| **在看** | 纵向列表（封面 + 进度 + 平台） | 能：续播队列 / 时间轴（按"下一次看"排序） | **原创增量** | 队列序号 + 剩余时长，而非纯列表 |
| **详情页** | Hero + 播放/收藏/更多 + 资源 + 演职员 + 家长指南 + 相似 | 能：加「技术徽章」条（4K/HDR10/10bit/码率/音轨） | **复刻结构 + 原创徽章** | kivo 硬解能力可视化，rex 没有 |
| **播放器 overlay** | 逐像素已对齐（轨道/按钮/面板/手势） | 结构与像素不必再改 | **保留复刻** | 只修 bug（面板锚定、手势状态） |
| **播放器 · 面板内容** | 右侧面板按触发控件锚定 | 能：面板加"技术信息"页（解码器/丢帧/码率） | **复刻结构 + 原创页** | 技术信息面板，kivo 独有 |
| **设置** | 分组行 + 环境/模块/播放/字幕 | 能：加「播放能力自检」（跑一次硬解/10bit/HDR 探测） | **复刻结构 + 原创子页** | 自检报告页，复用 P12 证据口径 |
| **搜索** | 独立圆钮 → 搜索页 | 能：统一搜索（本地 + TMDB + Emby 同结果） | **原创** | 结果分组 + 来源标签；rex 只搜在线 |

## 2. 原创收益排序（先做哪个）

| 优先级 | 项 | 理由 | 依赖 |
| --- | --- | --- | --- |
| P0 | 「我的」个人影院（已开工 P1） | 首屏叙事差异最大，rex 是仪表盘 | 无 |
| P0 | 详情页「技术徽章」 | 直接把播放内核优势摆在用户面前 | 需要播放器能力查询 |
| P1 | 播放器「技术信息」面板 | 极客用户与排障场景 | 同上 |
| P1 | 设置「播放能力自检」 | 把已有 P12 证据产品化 | 探测代码已有 |
| P2 | 资源库「源健康度」 | 多源用户刚需 | 源状态数据 |
| P2 | 搜索「统一结果」 | 本地+远程混合是 kivo 卖点 | 搜索索引 |
| P3 | 发现页 Hero 幕布叙事 | 视觉差异化，但不影响功能 | 无 |

## 3. 复刻清单（明确不做原创，避免画蛇添足）

- 底部导航结构、4 Tab 顺序、搜索圆钮位置。
- 发现页各横滑区的列数/比例/间距（2:3、16:9、5 列、2 列）。
- 播放器 overlay 的轨道 6pt、按钮 pitch 65、面板 248/16/42-60、锁定矩阵、HUD 150/1000/300。
- 设置页的分组结构与行高。
- 详情页的资源列表、家长指南、相似作品结构。

## 4. 防抄袭的具体做法

1. **不复制素材**：不使用 rex 的图标字体、渐变角度、品牌字标字体；平台字标用文字 + 品牌色近似。
2. **不复制文案**：空态/引导句全部自写（已发生：`还没有待看的影片` 是 rex 原文，后续替换为 kivo 语气）。
3. **结构差异可举证**：原创项必须在同屏并排中出现「rex 没有的模块」（技术徽章、源健康度、续播队列、自检页）。
4. **保留对比证据**：每个原创页在 `docs/audit/golden/` 留 rex 与 kivo 并排图，注明差异点。

## 5. 执行方式

- 每开一个新页面/模块，先在 §1 补行并写结论，再派编码任务。
- 原创项必须附「差异点」与「证据图」；复刻项必须附「对齐判据（px/dp）」。
- 与现有批次的关系：B4（播放器）继续；P1（我的）继续；B3 平台卡补品牌色；其余按 §2 排序逐步推进。
