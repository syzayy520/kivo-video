# 首页海报切换设计

2026-11-08。用户要求消除生硬切换，并吸收多款播放器的优点；目标是 Kivo 自己的体验，不再以全页复制 REX 为目标。

## 观察与边界

用户录屏 IMG_0141.MP4 的 18.9–19.3 秒存在海报横向切换和松手收敛，片名也参与横向过渡。不能从少量视频帧推定原版弹簧常量。当前 Kivo 整页匀速搬移、背景只在 settled 后跳色、指示点突然跳变，以及邻页临时加载，都是本次明确修正的实现问题。

## 状态与变换

拖动 → 取消返回原页，或松手吸附新页。Pager 是唯一位置和速度来源；不添加计时自动切页，不让多套动画争抢手势位置。

- 媒体保留原构图，按页偏移增加最多 5.5% 宽度的内部视差和 2.5% 的轻微缩放；图片在固定裁切区域内部运动，边缘不漏底。
- 片名、简介和评分是独立前景组，按偏移增加 6% 宽度位移，并渐隐至 35%；回到页中心准确恢复布局。单独变换不改变媒体构图基线。
- 环境色按连续页位置在相邻两页取样色之间插值；反拖和取消自然反向恢复。邻页未取得色值时使用已知相邻色，不插入黑色或默认白色闪帧。
- 指示点的大小与透明度跟随相同位置连续变化。
- 松手使用无过冲弹簧（阻尼比 1、刚度 240）；这两个数是 Kivo 的设计值，后续按真机手感修订，不能称为 REX 原始参数。
- 预组合左右相邻一页；海报加载与 logo 查询独立，慢 logo 不阻挡图片。预告仅在用户开启、当前页停稳且可见时运行；开始拖动即取消，预加载邻页不创建预告。

## 验收

K40 真机覆盖慢拖、松手、反拖取消、连续快速切页、纵滚后切换/回顶、下拉释放、进入详情再返回。默认预告关闭时不请求视频；开启时拖动不播放邻页视频。记录图像的空白、串图、色场跳变及返回状态；截图不能证明帧率，录屏也不能代替独立帧时间测量。不宣称完成全应用像素验收。
