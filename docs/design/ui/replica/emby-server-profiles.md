# Emby 多服务器与粘贴识别（2026-11-09）

> 历史候选，架构已由[统一资源库重构设计](../library-rebuild/plan.md)替代。下文“分页方案继续”及Emby独占存储/管理目录不再作为实施指令；保留加密、原子保存、显式粘贴等原则，实施以新家族树为准。

用户纠正第一版流程：应可添加多个服务器、保存账号、自定义名称、从分享文本粘贴识别。此方案替代第一版“凭据仅内存、返回连接表单”的产品决定；分页方案继续。

入口先展示服务器卡片，数量无产品硬上限；卡片显示自定义名称、地址、用户名，点击复用已保存令牌进入。菜单编辑/删除，删除二次确认。新增独立表单，名称可选（默认主机名）；连接成功才保存。编辑失败保留旧记录。返回服务器列表不删除记录。令牌失效仅在401时用保存凭据重新认证一次，其他网络错误不伪装账号失效。

凭据、令牌及服务器列表整体以 Android Keystore AES/GCM 加密，AtomicFile 写入 noBackupFilesDir，不参与备份；不得写明文到 SharedPreferences/日志/证据。不静默覆盖损坏存储，读取/写入失败给出可见原因。

显式“粘贴识别”读取剪贴板，不后台监听。支持中英文标签的名称、地址、端口、账号、密码，完整 URL、无协议域名、URL userinfo（解析后移除）。保留服务路径；独立端口补入地址；未知/多个服务器地址不猜测，提示手动检查。只填入识别字段，不自动连接；显示识别字段名称，不回显密码。服务器地址框粘贴整段分享文本时也走识别。解析器不做网络请求。

自然家族树：
- emby/servers/EmbyServerProfile.kt：保存记录。
- emby/servers/EmbyServerStore.kt：密钥、加密、原子持久化。
- emby/servers/EmbyShareParser.kt：无 Android 依赖文本解析。
- emby/EmbySessionModel.kt：列表/表单/已登录页导航及连接协调。
- emby/ui/EmbyServersScreen.kt：服务器卡片与删除确认。
- emby/ui/EmbyConnectionScreen.kt：名称与粘贴入口。
- emby/library/EmbyLibraryModel.kt：沿用分页职责。
- androidTest/.../emby/：合成凭据解析/加密/重建读取测试。
- docs/evidence/p240/emby-server-profiles/：脱敏平板验证。

参考范围：已有六播放器证据只涵盖首页/详情，不能当作其 Emby 功能实测。平板未装用户点名的 iOS 播放器；检查 iPhone 是否在线后再观察可用入口，不能冒充已研究它们的登录页。上述能力以用户明确需求为准。

验收：合成分享格式、特殊字符、歧义地址、空密码；至少两记录加密保存并重建读取/编辑/删除；真机真实连接、进程重启后卡片仍在且无需重填、分页>60、服务器搜索及错误可重试。手机尺寸与其他播放器 Emby 实测不足须如实记载。
