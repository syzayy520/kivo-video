# R2 · 详情交互闭环

2026-11-08。起点 `9ec7c3af`。先设计后实现；本卡不改媒体、渐变与片名的分层契约。

## 构思与证据边界

现有详情的心形、收藏夹图形、更多仅绘制；相似影片回调为空；简介固定两行；空资源的待看文案不可点。代码全域搜索未发现收藏/待看服务。`stats/WatchStore` 是本地路径的播放进度与时长，不能作为 TMDB 标记仓储。

REX 包内文案证明收藏、待看独立存在，不能证明手机 1.1 的图标点击语义。Vidora 的详情截图支持状态区分；Reflix 支持明确动作反馈。以下菜单与状态规则是 **Kivo 产品设计**，不冒称从原版提取：心形切换收藏，原收藏夹图形打开“影片标记”菜单（待看、已观看），更多提供 TMDB 详情与重新加载。收藏夹入口有操作标签和已标记反馈；不把收藏夹图形直接解释成待看图形。

## 状态与流程

- 身份是 `movie:<id>` / `tv:<id>`。收藏、待看、已观看三个独立位；手动已观看不伪造播放记录，也不自动取消待看。
- 首读：加载 → 可操作；失败 → 显示原因与“重试标记”。写入：可操作 → 正在保存（禁重复提交）→ 原子落盘后发布状态/成功反馈；失败保持已确认状态，显示原因，可重新操作。不依赖网络，不声称云同步。
- 全进程仅一个仓储实例供页面订阅；磁盘读写串行，写入前重新读取，避免覆盖其他影片。文件损坏不静默清空或覆盖；写入失败回滚临时文件。原子文件只存影片标记，不碰续播与资源。
- 长简介默认两行；确有溢出时显示“展开”，展开后显示“收起”。状态可恢复；不溢出不出现多余按钮。
- 相似影片保留当前电影/剧集类型（TMDB `/movie/id/similar` 与 `/tv/id/similar` 分型），独立 Activity 入栈；返回保留原列表状态。导航入口有离页锁，`onResume` 后解锁；一次连续点击只启动一页。当前影片不再打开自身。
- 详情加载失败在可见前景提供原因与重试；不把错误字藏在首屏之后。外部预告明确为 YouTube；无法打开时提示原因。网络不可达由外部播放器/浏览器处理，不宣称应用能判断外部视频已播放。

## 弹层视觉修订（用户反馈后）

废弃右侧 DropdownMenu。影片标记和更多操作共用一套浅暖灰底部卡片：顶部 30dp 圆角、24dp 内容边距、20sp 标题、独立 48dp 关闭触控区；操作行使用 18dp 圆角白底、44dp 线性图标底座、16sp 主文字和 12sp 次文字，选中以低饱和紫灰底与勾选双重表达。默认卡片内容随高度自适应，可滚动，保留底部安全区；背景轻遮罩。

交互使用 ModalBottomSheet 的进出动画；跳过半展开，打开直接显示完整操作。下拉、点遮罩、系统返回或关闭仅收起，不写状态；标记点击立即提交保存，同时动画收起，避免把存储延迟到退场之后。外部导航和重新加载则在收起后执行。收起期间禁再次提交。保存失败仍由详情原有错误/重试反馈承担，不伪装成成功。属于 Kivo 自有设计，不称原版测得参数。

## 验收

构建与覆盖安装；真机验证：三种标记独立添加/取消、跨影片隔离、返回/force-stop 后重进、长简介展开收起、相似跳转/原位置恢复/快点去重、无资源可见反馈、加载失败/重试、播放/预告入口回归。原子存储测试必须验证失败不把成功状态发布、损坏文件不被覆盖。截图/操作记录与测试输出归档；未覆盖的影片类型、布局边界与外部预告网络明确列出，不以本卡称整页像素验收完成。
