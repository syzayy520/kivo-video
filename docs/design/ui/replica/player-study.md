# 播放器参考观察与 Kivo 取舍

> 2026-11-09 新增的六款资源库/服务器表单研究另见[资源库研究矩阵](../../../reference/player-libraries/README.md)。本页保留此前首页/详情观察；尤其Forward此前未能打开的局部流程，不代表其资源库现状。

2026-11-08。目标是吸收有用的体验原则，形成 Kivo 的页面与交互；“像素级”用于约束实现精度，不再要求整页照搬 REX。当前只研究首页、详情与媒体过渡，不评价播放性能、HDR、付费或长期稳定性。

## 统一设计决定与后续顺序

1. 本卡先修动作质感：首页拖动时媒体/前景分别位移，色场和指示点连续过渡，取消反向恢复；详情仅媒体随上滑轻微放大。保留当前已认可的静止布局。见 [hero-transition.md](hero-transition.md)、[detail-media-motion.md](detail-media-motion.md)。
2. R2 接上收藏、待看、更多和相似影片跳转。采用清楚的动作语义与状态反馈；复用现有状态服务，先查职责再设计，不能直接复制他人的图标组合。
3. R3 处理动态 feed、缓存/失败与可选预告的完整生命周期。默认图片；上游更新可反映，但不保证每天片单不同。
4. R4 再逐页处理搜索、资源库、设置，统一字号、间距、材质与空态；参考分类方式时，以 Kivo 已有功能为依据。
5. R5 最后独立处理播放控制和手势，不借视觉卡改解码、时钟和 Surface。

没有实际操作的功能保持“未测”。本轮没有足够证据对六款应用作总体优劣排名，也没有完成所有应用的全部动效盘点。
