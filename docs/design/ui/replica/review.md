| 旧位置/结论 | 处置 | 原因与替代 |
| --- | --- | --- |
| 237 开头“帧测与 CSV 冲突以表为准”、§8“随包硬参数优先” | 作废 | CSV 多行明确写系统惯例/推断。用户决定优先，运行时实证与可核查包事实分层记录；版本不同先确认 |

| 237 “无详情/无 TMDB/无进度”，据此从零新增 | 现状描述作废 | 页面和数据域已存在；先盘点接线、状态与异常，不重复建一套服务 |

| 236–240 的“定稿/冻结/完成” | 限定含义 | 仅记录当时阶段状态，不证明当前全页像素级验收。本次用户认可当前效果，作为回归基线 |
| 239/交接词以 `posters[0]` 且禁止排序作为选图铁律 | 作废为全局规则 | 单片单次 API 顺序不稳定，且无语言不保证无字。现评分优先规则只是通用拟合，需多片验证 |
| 240“标题在海报里”及其后相反补丁 | 旧结论作废 | 用户与连续截图确认标题为独立前景；下拉只缩放媒体，滚动让前景覆盖底图 |
| 240 前 320dp 不提亮、固定阈值白字 | 被新真机观察替代 | iPhone 1.1 连续滚动显示更早转浅；亮图仍需根据实际色场可读性处理 |
| 240 的 507/585/589.5 高度与重复 §10/§11 | 历史参数，不整篇拼接执行 | 新分层设计按媒体/前景职责保存当前拟合；重新校准需记录实际设备与同状态素材 |
| 240/证据 status 将 430pt 全部乘 393/430；启动屏 nib 证明所有页面固定 393pt | 作废推论 | 启动屏尺寸不能证明运行布局。实际 scale/density、安全区、字体和触控区分别核对 |
| “backdrop 必无字、poster 必有字” | 作废 | 图片类型/语言元数据不保证图中文字；缺图、缺 logo 和有字图都要有明确策略 |
| 用单条 x=180 像素列、相邻色差≤25 验全页；不同片源全屏差分 | 作废为验收办法 | 同图同状态多区域测量；自然纹理不是接缝。P3/sRGB 转换、字体、状态栏分别报告 |
| 无第三方动效库→必是某原生框架默认 spring | 作废推论 | 依赖清单无法给出声明式布局和实际参数；真机测量优先 |
| 06 集成稿“全部文案级确定交互状态机”、35 行、资源已全量 | 修正 | 文案证明能力线索，不自动证明状态机；行数以解析产物为准；assetutil 元数据不等于原始图层素材 |
| 237 模糊“白色遮盖近似毛玻璃”，无定义相似度/无掉帧 | 限定/重测 | 材质须同背景对照；帧指标绑定设备实际刷新率、采样窗与原始输出 |
| 237 全 App 多模块同时改 | 调整顺序 | 当前基线→证据→详情动作→首页动态→其余页→播放器独立卡。每页真实交互闭环后再扩范围 |
