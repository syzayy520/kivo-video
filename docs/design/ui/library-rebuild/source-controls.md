# L2 服务器管理与隐私控制

2026-11-09。先设计再实现。SenPlayer USB 菜单实见服务配置、禁用聚合、默认首页、修改密码、修改图标、加密、删除；用户确认加密后卡隐藏，右上角锁解锁后显示。原始私人截图只留临时目录。

采用已有紧凑卡和浅色管理表单，增加可撤销动作，不引入新皮肤。隐藏服务器使用设备锁屏凭据验证，未设置系统锁时明确提示、不隐藏；不另存明文PIN。顶部锁控制本次前台会话的可见性，退后台/锁屏失效。已隐藏源不计入锁定态总数、不请求计数、不进入管理表单；直接源ID入口同样验证，后台返回不能展示旧内容。隐藏是本机访问控制，账号文件原有AES/GCM不变，不声称媒体文件被加密。

默认首页唯一，可取消；冷启动打开选定服务器一次，返回资源库不循环跳转；删除默认源回到发现页。隐藏默认源仍须验证。编辑账号保留全部偏好，修订号阻止过期设置覆盖。

首页聚合与聚合搜索是两个独立持久化开关。用户明确要求搜索排除用于家人/儿童隐私；隐藏源始终不参与两种聚合，即使暂时解锁也不自动加入。未来跨源搜索必须调用统一资格函数，先筛源再请求，建议/历史/缓存同域隔离。当前没有跨源聚合搜索或首页，菜单明确说明“接入聚合后生效”；不把现有单服务器内部搜索禁用，也不冒充TMDB内容分级。

家族树：
- sources/SourceRecord、SourceRepository：偏好与带版本事务；storage/SourceStore：schema1旧记录可选字段默认兼容，严格拒绝无效类型/多个默认。
- sources/access/SourceAccessSession：进程内授权、前后台失效；SourceUnlockController：系统凭据验证；SourceEligibility：可见与聚合范围纯规则。
- sources/ui/SourceManagementSheet：紧凑管理动作；SourcesScreen：锁、过滤、设置入口。
- MainActivity：默认启动一次；emby/EmbyActivity 与 EmbySessionModel：所有保存源入口验证。
- androidTest/.../sources/SourceControlsInstrumentation：隔离数据迁移、事务、隐私规则与授权失效；不修改真实服务器偏好或设备密码。

验收：构建；平板覆盖安装；菜单与撤销、无凭据拒绝路径、隔离真实Keystore事务测试；可用系统凭据下的人工解锁/取消/后台重锁若未测必须明示。证据归docs/evidence/p240/source-management/。L2仍DOING，后端不动；承接已归档平板自检，不重跑无关解码性能。
