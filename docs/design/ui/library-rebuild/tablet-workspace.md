# 平板资源库 · 页面双栏设计提案

2026-11-09。状态：实施中。用户“去做吧”已授权落地；此前弹窗内部双栏WIP保持撤回。本轮实现左资源库、右管理/编辑的页面关系。L2仍DOING，原有隐私与生命周期验收继续保留。

实施归属确认：workspace/负责容器、ID导航状态及可复用管理/连接内容；SourceManagementSheet和EmbySourceForm只做窄窗包装；SourceTypeSheet复用来源内容；cards/负责统一卡片外壳、入口卡及图标。SourceManagerModel仅补充草稿是否修改的事实，不复制认证、Repository和版本事务。来源品牌优先现有Emby与公开品牌图形，飞牛未核实官方标志前采用中性存储图形并明确预留。双栏先按W≥960dp且fontScale≤1.3落地，840–959暂沿用窄窗以保证可读性。不得把设计动效时长写成已测性能。

## 本轮裁决（覆盖下文旧尺寸与导航约定）

用户提供平板当前软件截图并明确：左右各一半、主界面保留导航、分页为独立页面。宿主覆盖整个窗口，左右边界为窗口中线；左页拥有自己的状态栏内容留白和底部胶囊导航，右页独立避让系统栏与键盘，背景贯穿上下。右页不继承主界面84dp导航留白，也不使用悬浮圆角面板。两页共用已有浅色背景，右页仅叠加低透明度白色，中央细线弱化。W≥960dp且fontScale≤1.3时采用等分，低于该范围继续复用窄窗包装器。

家族树维持既有workspace/与cards/；MainActivity提供共享导航槽，SourcesScreen将导航交给SourceWorkspace左页宿主，不复制导航逻辑与凭据业务。

## 设计判断

推荐按需展开的页面双栏。浏览时资源库占完整内容区；长按卡片或点击卡片管理入口，资源库收窄，右侧出现独立管理页。编辑连接在右页内前进，资源库始终可见、可滚动，没有遮罩。用户可辨认自己正在修改哪个源，管理多个服务器时少一次返回。

不把双栏永久占满首页：未选服务器时，资源库仍是浏览页面。也不把表单内部左右分组：名称、地址、账号、密码按阅读顺序纵向排列。左右页的职责是对象与操作。

视觉继承Kivo已认可的浅色、轻微洗色、紧凑密度；参考REX的卡片信息层级、SenPlayer的管理动作组织以及既有多播放器观察。双栏方案与下面的时长是Kivo设计建议，不是已观察到的REX实现参数，不声称新做过竞品实测。

## 空间与层级

2026-11-09 用户追加：本地影片、SMB、私密区入口也采用紧凑豆腐块，不再使用横向合并入口条。与媒体服务器卡片复用相同网格列宽、高度、圆角、边距、图标槽位及字号，分为“本地与存储”和“媒体服务器”两组，避免三个入口被拉伸成大块。单击分别进入本地影片、SMB连接列表、私密区验证流程。内容数量仅在真实可得时显示，未知不填0；私密区锁定时仅显示“已锁定”，不泄露封面、片名或数量。本地/私密区不显示服务器在线点；SMB分组入口不伪造整体在线状态，具体连接可按实测显示状态。此项Android已实施，最终真机验收继续进行。

按页面宿主窗口宽度W决策，单位dp，与屏幕像素分开；系统栏及键盘留白由两页各自处理。

| 条件 | 布局 |
| --- | --- |
| W ≥ 960，fontScale ≤ 1.3，右页已打开 | 左右各占一半；中间0.5dp低对比分隔线 |
| W < 960，或fontScale > 1.3 | 沿用窄窗sheet包装，共用同一份表单与管理内容 |
| 右页未打开 | 资源库占全宽，底部导航属于主界面 |

这是初始断点，须用真实窗口测量校准；不以“横屏”或“平板型号”硬判。分屏、多窗口、折叠窗口都用相同规则。双栏采用用户明确要求的等分，不再使用固定400dp右栏。大字号可增加行高与减少网格列数，不能缩字体强塞双栏。

左侧保留完整资源库：页面标题、添加/锁入口、本地与网络入口、媒体服务器紧凑网格。管理展开时允许列数减少，保持同一源ID与可见锚点，避免整页跳回顶部。应用级导航的位置、样式与入口顺序全部沿用现有底部胶囊及独立搜索按钮；不得迁到顶部、改成侧栏或在右页复制。右页不预留左页导航空间，仅避让系统栏与键盘。

右侧是贴边的独立页面，继承共同浅色背景并叠加24%白色色层，中间细分隔，无大阴影、悬浮圆角框或黑色遮罩。头部56–64高，内容边距24（窄栏20）；标题18–20sp、项目14–15sp、辅助12–13sp，点击目标≥48dp。卡片名称14–15sp、统计12sp，字随系统缩放。具体基线以真机效果定，不能把预览CSS像素直接当Android dp/sp。

卡片沿用官方Emby图标，不另造品牌图案；服名在上、电影/剧集数量在下、6dp在线点。名称最多两行；统计空间不足自然换行；未知/离线不伪造0。不设卡片选中态、不加选中描边；管理对象由右页完整名称明确。右上角三个点为固定可见的独立管理按钮，轻图形但有效点击区域≥48dp，和卡片主体不互相触发。长按卡片进入相同管理页。全名在管理页自然换行，图标/关闭按钮不挤压文本。

来源图标与文字统一：Emby、Plex、Jellyfin采用可辨认品牌图标；飞牛预览暂用统一存储图标，正式实现前核对官方飞牛影视标识，不冒用Emby图标。SMB采用网络存储图标加“SMB”文字，WebDAV采用云文件图标加“WebDAV”文字。图标放入同尺寸槽位（建议24dp），统一对齐、文字基线、间距及触控区域，不能统一成各色emoji。按用户要求保留全部六种来源；未实现时明确标“暂未接入”，不可进入虚假连接表单。预留项不计为已连接服务器，不显示在线状态或片量。

## 右页内容

### 管理页

头部“管理资源库”与关闭；下面为小型服务器身份区：官方图标、完整名称、在线状态和真实统计。地址/账号默认不作为展示装饰铺在首页，需要时在连接编辑查看。

动作纵向分组：

1. 连接：编辑连接（进入同一右栏内的表单）。
2. 使用偏好：设为默认首页、参与首页聚合、参与聚合搜索。文字表达当前状态，尾部开关表达启用关系，避免“禁用”与开关开着的双重否定。
3. 隐私：隐藏并加锁，旁边说明“验证身份后显示；退到后台重新锁定”。隐藏资格与聚合资格沿用现有规则。
4. 底部独立“移除资源库”，低强调红色文字，执行前点名确认。

聚合未接通时必须保留简短事实说明“偏好已保存，聚合接入后生效”；不通过设计预览把它包装成已运行的搜索保护。开关即时保存，保存失败回到原状态并就地解释；连接字段则使用草稿和显式保存，两个提交模型不可混用。

### 编辑页

头部返回管理、标题“编辑连接”、关闭。内容三组：名称；服务器地址（完整URL，端口/路径可展开核对）；账号与密码。密码默认遮挡，显式显示/隐藏；空密码合法。粘贴识别是次级入口，只在点击后读取，展示脱敏预览与冲突后再填入，不自动连接。

底部固定操作区“取消 / 验证并保存”，固定于右页可用底边，不横跨左页。未更改不激活保存；连接中显示进度，允许取消；磁盘提交短阶段不允许退出并明确“正在保存”。失败保留输入且不更改原源；成功返回管理，更新左侧名称及相关统计资格，保留原卡位置。

错误紧邻相关字段，连接类错误在提交区上方；不用一块占满右页的调试信息。高级项渐进展开，首屏不堆协议解释和将来才支持的功能。

### 添加

左侧“添加”→右页选择来源类型→对应表单。类型页统一“图标＋名称”排布，分为“媒体服务器”（Emby、Plex、Jellyfin、飞牛）和“文件存储”（SMB、WebDAV）。其中Emby接现有源管理；SMB已有独立网络入口，整合统一管理尚待完成；Plex、Jellyfin、飞牛、WebDAV先预留图标与名称，呈禁用态并标“暂未接入”，不触发登录。保存成功后新卡出现在稳定插入位置，右页展示新源管理，不给卡片加选中态。来源数量增加不限制产品上限，也不默认批量登录所有源。

后续接入分别设计连接/认证、服务身份、内容浏览、持久保存、错误恢复及播放回归。建议先收口现有Emby与SMB，再逐项接入Jellyfin、WebDAV、飞牛、Plex；此顺序为初步依赖安排，飞牛先明确采用飞牛影视接口还是SMB/WebDAV文件访问，不能用文件协议入口冒充完整影视服务。Jellyfin需独立兼容性验证，Plex需单独设计账号授权；共同复用来源管理与页面容器，不提前堆未验证的协议实现。新增卡片须遵循TASKS五项格式后才可开工，本轮仅预留设计。

## 交互连续性

| 触发 | 行为 |
| --- | --- |
| 任何状态下单击卡片主体 | 始终进入该服务器媒体页；如有未保存编辑，先处理草稿退出确认，再导航 |
| 长按卡片/右上角三个点 | 展开双栏，右页显示该源管理；卡片无选中态 |
| 右页已展开，长按另一卡/点另一卡三个点 | 切换右栏管理对象；单击主体仍进入服务器，不存在改变单击含义的管理模式 |
| 编辑草稿有修改，再切源/关闭/返回 | 提示“继续编辑 / 放弃修改”；不静默保存，也不先切换对象 |
| 编辑无修改时切源 | 直接切换；不重复弹确认 |
| 保存中切源 | 验证阶段可取消；进入提交阶段短暂阻止切源，完成后再处理 |
| 系统返回 | 先由系统处理键盘；随后编辑→管理→关闭右页→离开资源库 |
| 锁定/退后台 | 隐藏源页和草稿从可见树移除，清焦点/键盘，遵守现有授权规则，不能在淡出中残留可读秘密 |
| 转屏/分屏改变宽度 | 同一管理对象ID和草稿迁移为单页或双页，保留滚动锚点；不重复验证或提交 |

2026-11-09用户裁决：作废改变卡片单击含义的管理模式。单击进入、长按/三个点管理始终一致；不设置“管理中”选择模式。长按成功须抑制随后抬手产生的单击，手势滑动时取消长按识别；三个点事件不能冒泡成进入服务器。

默认首页唯一、首页/搜索聚合独立、隐藏后不参与聚合等既有业务规则不在布局层重写。标题区避免露出隐藏源数量或名称；认证取消后不能保留预览。删除当前源则关闭右页并撤销选择，不自动跳到另一源，避免误操作对象改变。

## 键盘、动效与可访问性

键盘出现时右侧内容可滚动，表单操作区贴键盘上沿；左页保持横向尺寸与滚动锚点，整个窗口仍正常响应IME可用高度变化。焦点字段、错误和保存操作都必须可到达；不依赖截图中“看起来能放下”。键盘关闭不弹跳回表单顶部。

首次展开建议220–260ms：左侧平滑收窄、右侧随边界展开；文字按最终宽度布局避免逐帧换行。不飞入大卡片、不弹簧过冲。管理→编辑建议180–220ms短距离横向前进；切换对象只更新右页并轻微交叉淡化，左侧无选中视觉。减少动态效果时立即完成布局，允许极短淡化。以上全为待验设计值。

屏幕阅读顺序：应用导航→左页标题与卡片→右页标题与操作；展开后焦点到右页标题，关闭后返回触发卡。用“在线/离线/未检测”无障碍文字补充状态点；开关朗读对象与状态；键盘/遥控器可到达管理入口，无需长按或悬停。

## 自然家族树（实施归属）

```text
sources/
  SourceManagerModel.kt                 既有草稿/验证/提交与版本事务
  ui/
    SourcesScreen.kt                    资源库与页面宿主组装
    SourceCard.kt                       紧凑卡/单击进入/长按及三个点管理
    workspace/
      SourceWorkspace.kt               单双页测量与容器；不负责认证
      SourceWorkspaceState.kt          管理对象ID、右页路径、退出草稿决策
      SourceManagementContent.kt       可嵌入的管理内容
      SourceConnectionContent.kt       可嵌入的连接内容
    SourceManagementSheet.kt           窄窗口包装器，复用内容
    EmbySourceForm.kt                   窄窗口包装器，复用内容
```

单页、双页共用字段/动作与状态，不复制Repository、凭据验证或保存逻辑。workspace只处理页面关系；协议差异仍归协议表单。实施前先审阅现有文件职责，再决定是否需要上述每个文件，不能先建空壳。
