① 搜索首页

  • 34pt 大标题 + 白色毛玻璃搜索框（46dp / 圆角 14），沿用首页页面渐变底。
  • 分类六宫格直接复用首页「分类浏览」卡的语言：剧照、左暗渐变、中文加字距英文。配图取该分类当天热度第一的剧照，每天会变。
  • 最近搜索用胶囊；热搜榜收进一张白卡，前三名序号加深，上升和新上榜用小标注，不用彩色色块。
  • 底栏放大镜进入选中态：白底加蓝色描边，和其他四个 Tab 的选中逻辑区分开。

② 输入中

  • 输入框获得焦点时出现蓝色细光圈，右侧出「取消」，底栏让位给键盘。
  • 最佳匹配用剧照大卡加「播放」按钮，搜到就能直接播。
  • 结果行标出来源：绿点「NAS 可播 · 4K」，灰点「TMDB · 未入库」，用户一眼知道哪些能看。
  • 命中的关键字用系统蓝加粗；键盘联想栏同步给出补全词。

③ 分类筛选

  • 顶部文字 Tab 切六大分类，选中项加粗并带一根 16dp 短下划线。
  • 排序用 iOS 分段控件：最近更新 / 最新上映 / 影片评分。
  • 类型、地区、年份三行横滑胶囊，选中项用正文黑底白字；往下滚时三行收成一行摘要「电影 · 犯罪 · 2025 · 最近更新」吸顶。
  • 「只看可播」开关用品牌绿；海报三列，只有 4K / HDR 显示在右上角。
