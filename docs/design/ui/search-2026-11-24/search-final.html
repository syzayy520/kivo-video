没吸收的

  • 对齐首页风格稿：生成的色块占位代替真实封面，角标出现 1080p，和已定的「只留 4K / HDR」冲突。
  • 分类改横滑（v2 / 精修稿）：六个分类只露出 2.5 个，用户要找「纪录片」得先滑。定稿改成 3 列 × 2 行，一屏全见，高度只比横滑多 9px。
  • 类型/地区/年份全收进下拉（精修稿）：更省空间，但筛选项被藏起来，要多点一下才能看到。定稿保留三行横滑胶囊，只把排序收成下拉。
  • 海报下写时长（精修稿）：和首页「★ 评分 · 年份」口径不一致。

落地注意

  • 底栏玻璃化（白 66% + 亮边）改的是全局 CapsuleNavBar，会影响首页等所有页；如果只想改搜索页，就保留现有 #E8E9ED 实心胶囊。
  • 取色渐变的 --tint = 封面下半部主色压暗到亮度 ≤20%，项目里已有 PosterPalette.kt 可复用。
  • 分类卡请用 TMDB 无文字剧照（include_image_language=null），本稿素材从截图裁切，个别带片名字。
  • ④ 的吸顶摘要在筛选区滚出视口时出现，点摘要展开回三行筛选。
