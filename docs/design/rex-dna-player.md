# REX 播放器 DNA（合成稿）

> 2026-11-17 ｜ 来源：`PlayerTokens` 逐像素实测（横屏 2532×1170 @3x）、播放器审计 135 条、`Rex_动效参数表.csv` M03/M05/M08。
> 证据等级：✅ 实测/参数表确定 ｜ ◐ 推断 ｜ ❌ 未知。**本文件不引入任何新代码。**

## 2. Typography DNA（✅/◐）

- 面板标题 15–16sp 粗；行标题 14–15sp；分区标题 12sp；chevron 12dp。
- 时间标签 12sp 等宽数字；文本钮（4K/选集/倍速）13sp。
- 长按倍速 HUD：标签 20sp 粗、副标 12sp。
- 无衬线、无艺术字；标题层级只保留 3 档。

## 3. Spacing DNA（✅）

- 顶栏 19 / 图标 50 / 面板内 16 / 行高 42（常规）·60（带副标）/ 行图标 18 / 勾 14 / 右侧 16。
- 面板宽 248、圆角 16、最大高 330、滚动条 3dp、内缩 6dp。

## 4. Color & Scrim DNA（✅）

- 文字：白 / 白 70% / 白 45% 三档；不可用 30%。
- 遮罩：顶部**无**；底部 110dp 黑渐变（底部最深处约 55%）。
- 面板：`#1C1C1E` 92% 不透明 + 1px 白 8% 描边（暗态玻璃近似）。
- 强调色：白色（选中勾/活动轨道），**不用品牌绿**。
- 进度：已播 白 90%；缓冲 白 35%；未播 白 22%。

## 5. Icon DNA（✅）

- 线性 1.5–1.8dp 描边、23dp 画布；填充态仅用于选中勾（14dp）。
- 顶栏 8 槽位：投屏 / 弹幕 / 画中画 / **场记板（填充模式+比例）** / **圈✓（跳过片段）** / 耳机 / 字幕 / 听视频。
- 左侧：✕（22dp 级）+ 主页（19dp 级）——**✕ 略大于主页**（◐ 待高分辨率确认）。
- 底部左组：暂停(主) + 15s 回退/前进；右侧文本钮。

## 6. Focus / Press DNA（✅/◐）

- 移动端无焦点环；按下态 `pressAlpha 0.6`。
- 长按触发阈值 0.5s（M03-S02）；双击识别窗 0.3s（M03-S01）。
- 锁定态：长按与双击**仍可用**，其余手势禁用（确定项）。

## 7. Animation DNA（✅ 参数表）

| 动效 | 时长 | 缓动 | 位移/缩放 | 备注 |
| --- | --- | --- | --- | --- |
| 控件出现 | 180ms | easeOut | Δy = 自身高/6 → 0 | 位移+α |
| 控件隐藏 | 140ms | easeIn | 0 → Δy | 位移+α |
| 面板出现 | 150ms | spring | 0.94→1 + 6dp 位移 | 锚在触发控件 |
| 双击反馈 | 图标 0.5s | easeOut | α 0→1→0 | 中间播放暂停/两侧 seek |
| 长按 HUD | 进 0.2 / 退 0.15 | easeOut | 0.9→1 | 停止 1s 后淡出 |
| 音量/亮度 HUD | 0.15 进 / 0.3 出 | easeOut | 位置随手势 | 停止 1s 后淡出 |
| 换集过渡 | 0.3–0.5s | easeInOut | 交叉溶解 | 与预加载耦合，可关 |
| 错误抖动 | 0.1×3 | linear | Δx ±6pt | 仅输入/操作失败 |

## 8. Transition DNA（✅）

- 进入播放器：从详情/列表**直接推入**，无缩放；播放器内控件先出后隐。
- 退出：先退控件 → 返回来源页（落点恢复）。
- 换集：硬切（关）或交叉溶解 0.3–0.5（开）。
- 页面级：sheet 0.35 spring；侧栏折叠 0.25。

## 9. Background & Media DNA（✅）

- 视频铺满，`SurfaceView` 独立合成；控件叠在视频上。
- 无封面时：纯黑 + 居中 spinner（起播动画可关 → 回退系统加载圈，M01-S08）。
- 亮度/音量独立 HUD，不遮挡画面中心。

## 10. Information Hierarchy（✅）

1. 画面本身（最大）。
2. 片名/集数（顶栏左侧，单行）。
3. 进度与时间（唯一的数据区）。
4. 控制（底栏）。
5. 元信息（面板内，按需展开）。

## 12. 可迁移 vs 不可迁移（Android）

| REX 做法 | Android 落地 |
| --- | --- |
| 状态行自绘 | 保留（已实现） |
| iOS 毛玻璃 | 92% 不透明 + 1px 描边；API31+ 可 `RenderEffect` 近似 |
| Reduce Motion（系统） | `MotionGate`：系统 animator scale + App 开关取或 |
| 触觉三态 | `HapticFeedback` + 低电量降级 |
| 15s 快退/前进 | 保留（已是项目语义） |
| 交叉溶解换集 | 首帧 Bitmap 叠层 300ms 淡出（`screenshot-to-file` 已有能力） |

## 13. 必须复刻（不得改）

- 轨道 6pt / 三段半透明 / 无滑块 / 描边。
- 节距 65 / 底栏 33 / 左右 16 / 面板 248·16·42-60·3pt。
- 顶栏 8 槽位顺序与语义（第 4 场记板、第 5 圈✓）。
- 锁定态手势矩阵。
- 控件隐藏时**无控件残留**；顶部**不加遮罩**。

## 14. Kivo 可超越点（初判，需举证）

| 候选 | REX 现状 | Kivo 方案 | 为什么更好 | 验证 |
| --- | --- | --- | --- | --- |
| 技术信息面板 | 无（只有音轨/延迟） | 面板增「技术信息」页（解码器/位深/HDR/码率/音轨/丢帧） | 把已调校的硬解能力可视化，排障与极客用户直接受益；不改 overlay 结构 | 与 REX 同屏并排：多一个面板页，其余不变 |
| 选集态进度条 | 保留轨道 | 已修正为保留（B4） | 与 REX 一致 | 已对齐 |
| 双指缩放 | 有（1.0–2.0） | 已实现但需真机确认 SurfaceView 是否受 graphicsLayer 影响 | 若无效改内核 video-zoom，不改 UI | 真机双指 |
| 减弱动效覆盖 | 全量 | 目前仅 2 处（审计 MOT-02） | 补全后与 REX 持平 | 逐项开关验证 |

**结论**：播放器 overlay 结构与像素**必须复刻**；唯一允许的增量是「技术信息面板」，且不改变任何既有槽位与几何。
