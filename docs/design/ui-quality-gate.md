# UI 质量门（硬性，所有页面适用）

> 2026-11-17 ｜ 背景：原创版「我的」因未设质量门而做出远低于 rex 的密度，被用户否决。
> 规则：**能做到比 rex 好就原创，做不到就 1:1 复刻**；任何页面不得以「结构有了」代替「看起来一样好」。

## 一、三条硬门（缺一不算完成）

1. **同屏对比**：每个页面/模块必须产出「基准（rex 或 B2 版截图）｜当前实现」左右并排图，落在 `docs/audit/golden/cmp/`。
   没有并排图 = 没有验收证据，不得标记完成。
2. **密度**：首屏（不滚动）必须至少容纳 **4 个完整模块**；相邻模块间距 ≤ 16dp；**不允许出现高度 > 48dp 的纯空白带**。
3. **尺寸**：卡片宽/高与基准的差 ≤ **8dp**；列数与基准一致；文字层级（主/次/数值）差 ≤ 2sp。

## 二、逐页判据

| 页面 | 必须达到 |
| --- | --- |
| 发现页 | 与 0330–0335 同屏对比；6 个新模块全部渲染；hero/横滑区尺寸 ±8dp |
| 我的 | **复刻 B2 版**（`docs/audit/golden/kivo/profile-1..5.png` 为基准）：环境头/周历/今日/历史/待看/收藏在看/本月/TOP3/类型/趋势/管理 全部在同屏滚动内，密度不低于基准 |
| 资源库 | 与 0366–0370 对比；网格卡 + 计数 + 分组 + 五段式添加 |
| 详情 | 与 0341–0343 对比结构；技术徽章为原创增量，不得挤掉原有信息 |
| 播放器 | 与 0159–0173 对比；overlay 已对齐项不得回退 |

## 三、禁止

- 未做并排对比就宣称「达成」。
- 用「空态/数据缺失」解释大面积留白——空态也必须给出紧凑、有信息量的设计。
- 在没达到基准密度的前提下继续做「原创美化」。

## 四、流程

设计 → 实现 → **并排截图** → 按 §一/§二 逐项打勾 → 不达标打回同一负责人重做 → 全部通过才进入下一批。
