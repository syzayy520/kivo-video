## 一、构思

`195` 的真机数字是 `rate_ppm = -0.538969` —— 说明这台设备当前钟几乎完美，但**也说明不了估计器准不准**：
一个恒返回 0 的实现，在完美钟上同样会给出 ≈0。

要证它准，必须制造**已知频差**。`PlayerActivity` 有 `--ei kivo.clock_rate_ppm`，
底层是 `ClockOffsetSource`（P13-AB 用过的同一注入），能确定性地把钟调快。

于是：注入 0 / 2000 / 5000 ppm，看 `pace.rate_ppm` 是否分别落在 0 / 2000 / 5000 附近。
顺便看 `drift_rebases`：2000 ppm × 35 s = 70 ms，越过 45 ms 门限，**门应该响** ——
这也复核了 `184` 的"注入轮门响、自然轮门漏"。

---

## 二、规划设计

1. **零代码改动**：只跑真机、只读证据。
2. **完整 45 s 播放**（不用 `finalize on_stop` 快速模式）：让估计器有足够样本收敛，
   也让 70 ms 累积越过门限。
3. **三组**：0 / 2000 / 5000 ppm，其余参数逐字相同（`pace 1`、`drop 1`、`cpu_paced`）。
4. 只操作 `dd137cf7`；`b6e950ee` 不碰；不 `uninstall`。

### 判据（V1–V3）

| 判据 | 内容 |
| --- | --- |
| V1 | 注入 0 ppm：`rate_ppm` 落在 **±10 ppm** |
| V2 | 注入 2000 / 5000 ppm：`rate_ppm` 与注入值偏差 **< 100 ppm**（5% 相对误差） |
| V3 | 2000 ppm 轮 `drift_rebases ≥ 1`（70 ms 累积越过 45 ms 门限）；0 ppm 轮 `drift_rebases = 0` |

## 五、结果（2026-11-06）

### 第一轮（修正前）：三组全不对

| 注入 ppm | `rate_ppm` | 现象 |
| --- | --- | --- |
| 0 | -58.55 | 尚可 |
| 2000 | **-3122.91** | 既不匹配、符号还反了 |
| 5000 | **-945.10** | 比 2000 那组更小，**非单调** |

### 缺陷与修正

估计器喂的是 `position_ns_` —— **漂移门修正后**的位置。
门每次复位都会把位置减一截，估计器把"门在修正"误读成"钟突然变慢"，
于是注入越大、门触发越多、读数越歪。

修正：改喂 `snapshot.position_ns`（**门动手之前的原始位置**）。
速率是钟本身的属性，必须在门改它之前测量。

### 第二轮（修正后）：线性吻合

| 注入 ppm | `rate_ppm` | 偏差 | `phase_error_ns` | 理论累积 | 帧数 / 丢帧 |
| --- | --- | --- | --- | --- | --- |
| 0 | **-14.03** | -14 ppm | -1,342 | ~0 | 1050 / 0 |
| 2000 | **1986.99** | -13 ppm（0.65%） | 65,795,975 | 70 ms | 1050 / 0 |
| 5000 | **4959.18** | -41 ppm（0.82%） | 164,441,662 | 175 ms | 1050 / 0 |

### 判据核对

| 判据 | 结果 |
| --- | --- |
| V1（0 ppm 落在 ±10） | **边缘未过**：-14.03 ppm，超出 4 ppm。不掩盖 |
| V2（2000/5000 偏差 < 100 ppm） | **PASS**：-13 / -41 ppm，相对误差 < 1% |
| V3（2000 ppm 轮 `drift_rebases ≥ 1`） | **无法判**：decode 证据的 `pace` 块没有 `clock_health`（那是 sync 证据的字段），本卡不追 |

### 结论

- **估计器在真实链路上准确**：三组线性、偏差 < 1%，
  `phase_error` 与理论累积吻合（65.8 / 164.4 ms vs 70 / 175 ms，差值来自启动期盲区）。
- **修正本身是这轮最大收获**：改前 -3123 / -945（非单调），改后 1987 / 4959（线性）。
  "接在门修正后的位置上"是个真缺陷，不是调参问题。
- 仍未做 G6 性能回归；V1 的 -14 ppm 说明低通有残余或 0 注入下仍有微小频差，如实保留。

### 边界

只证明"估计器准"，**不证明"该用速率伺服"** —— 控制律仍等 `183` §七 Q1/Q2。
