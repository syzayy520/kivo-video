## 一、一句话目标

**把现有功能界面重铸成 Rex 的模样：4 tab 毛玻璃胶囊导航 + 动画渐变背景 + 毛玻璃卡片 +
录屏实测的网格/行高/字号——像素级对位，不再"借几个 token"。**

## 二、全局 tokens（05 号规格 + **帧实测修正**，直接采用）

> 帧实测 = `Pictures/REX/frames/` 全分辨率帧 ÷3 换算（@3x）。两处修正 05 号粗测值：
> ① 海报卡标题实测 **15–16pt**（非 12pt）；② 日期行 **13pt 灰、完整日期 yyyy-MM-dd**（非 10pt 年份）。
