# 112 · P13-AD 验收：门把"无界累积"压成"固定 40 ms"，与 ppm 无关

- 日期：2026-10-30
- 前置：`111-p13ad-design.md`
- 结论：**五轮全中**。1.5% 与 5% 两种速率误差，门关时 `clock_ahead` 长到
  103 / 332 ms、`playback_rate` 1.0131 / 1.0434；门开时**两者都停在 40.0–42.8 ms、
  1.0050–1.0054** —— ppm 翻三倍多，残差不动。这是整个 P13-A* 系列最强的一次对照。

---

## 一、五轮（4K60 / `cpu_paced` / 音频主时钟 / 零丢帧）

| 轮 | 速率 | 门 | `drift_rebases` | `clock_ahead` | `playback_rate` | 单帧迟到 max | p99 |
|---|---|---|---|---|---|---|---|
| `clean` | — | on | 0 | +0.04 ms | 1.000013 | 8.55 ms | 0.38 ms |
| `rate15-off` | 1.5% | **off** | **0** | **+102.97 ms** | **1.013065** | 12.71 ms | 4.12 ms |
| `rate15-on` | 1.5% | on | 12 | **+42.79 ms** | **1.005402** | 4.64 ms | 1.88 ms |
| `rate50-off` | 5% | **off** | **0** | **+331.77 ms** | **1.043374** | 10.95 ms | 6.02 ms |
| `rate50-on` | 5% | on | 57 | **+40.00 ms** | **1.005048** | 6.02 ms | 1.12 ms |

- 门关：`clock_ahead ≈ ppm × 时长`（1.5% → 103 ms，5% → 332 ms，线性）。
- 门开：**1.5% 与 5% 的残差都是 40–43 ms**，与 ppm 无关；触发次数随 ppm 上升
  （12 → 57），那正是"追得更勤"的代价，而不是"错得更多"。
- 修掉的总量（`drift_corrected_total_ns`）：61.07 / 306.09 ms = 各自累积量 − 残差。

## 二、这一卡纠正了两件事

### 1. 判据不能写"速率回到 1.000"

门压的是**相位**，不是速率：它把位置拉回 40 ms，但位置照样以 1.5% 增长，
每次涨过线就被拽回来。所以 `playback_rate` 停在 `1 + 40 ms/时长 ≈ 1.005`，
而不是 1.000 —— 要改速率只有重采样能做到。

正确的判据是"**`clock_ahead` 有界，且与 ppm 无关**"，本轮 40.00 / 42.79 就是这个证据。

### 2. 台阶是合成输入，这一点现在有数据了

| | 台阶（80 ms） | 速率（1.5%） |
|---|---|---|
| 单帧迟到 max | 23.96 ms | **4.64 ms** |
| p99 | 0.38 ms | 1.88 ms |

渐变漂移**不产生尖峰**：它每帧只多 0.25 ms，门有充分时间追。P13-AC 里
"一次还完 vs 限速"的争论，在真实形状下几乎没有差别 —— 那句话此前是推理，现在是两张表。

## 三、量级换算

1.5% 的速率误差，门关时：

| 时长 | 累积偏移 |
|---|---|
| 8 s（本片源） | 103 ms |
| 1 min | 0.9 s |
| 10 min | 9 s |
| 2 h | **108 s** |

门开时全程 40–43 ms。这是"有门"与"没门"的全部差别。

## 四、诚实清单

1. **注入是合成的**：`pos' = origin + (pos − origin) × (1 + ppm)` 直接改位置，
   真实的 HAL 报数是采样式的（`AudioTimestamp` 帧位置 + 外推），未测。
2. **只有 1.5% 与 5% 两个点**，没有扫频；门在 0.05%–0.5% 这种"接近正常"的
   速率误差下会不会误触发，没测（P13-AB 的无注入轮 `rebases = 0`，
   但那只是零误差）。
3. **前提**：门假设"时钟的估计错了"，不是"播放真的快了"。晶振典型 ±100 ppm，
   1.5% 差两个数量级，所以这个假设对本机成立；若真遇到音频确实快放，
   正确处置是重采样，不是改相位（`111-p13ad-design.md` §六）。
4. **`drift_gate` 开关只用于探针**：`PacePolicy` 里是普通字段，生产路径恒为 true，
   没有从配置文件读它。
5. 校验器 I2 一开始只按 `offset_ns == 0` 判"没注入"，把四轮速率证据全判成
   "幽灵注入点"。已改成 `offset == 0 且 rate_ppm == 0` —— 判据要跟着输入的
   种类一起长，否则新输入会被旧判据误杀。
