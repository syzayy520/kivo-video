# 首页与详情页：背景、幕布、前景分层

## 构思与依据

用户确认两页都修。IMG_0149–0158 显示背景树木位移远小于 logo/内容位移；logo 属于前景。390pt 归一化测得 logo 上移约 352pt 时，上方树林仅约 18pt 可可靠跟踪，取 5% 轻视差作为拟合值，不冒充静态拆解提取的常量。背景选图必须先正确，再比较布局。

## 规划

- 首页保留唯一 pager 和预告片生命周期；只对媒体层补偿列表真实滚动的 95%，幕布、logo、文字、分页点仍在列表前景。下拉仅媒体缩放，片名不缩放。
- 详情列表首项整合为标题/主信息/资源区，首项高度超过 700dp。由 LazyListState 实际消费偏移计算渐变；首项离屏时颜色已完全浅化。禁止用手势 available 累积替代列表位置。
- 详情底图使用 images.posters 中优先无语言竖图；没有时用无字横图，最后才本地化海报。选图按数据通用规则，禁止影片 ID 特例。TMDB 无语言不保证绝对无文字，该限制明确保留。
- 单一幕布从透明平滑过渡到环境色，顶/底边随内容上移。删除逐列表项的不透明硬切背景，深滚幕布填满视口。
- 默认静态海报；预告片仍须用户主动启用，保持 2s 延迟和整幅媒体替换。动态 feed 刷新机制不改为固定片单。

## 验收

构建与覆盖安装成功；K40 两页初始/中滚/深滚/回顶/下拉/横滑截图或录屏；背景不是随内容 1:1 离屏；前景片名独立，不随媒体缩放；无 meta 硬切边；深滚不漏图；回顶状态恢复。原图不同、字体平台差异和未测时长单列，未满足像素级全部验收不得宣称完成。

## 真机复核修正

iPhone Rex 1.1 已通过 USB 直接截图/手势验证。旧版按票数选图会优先荒野丛林白底图（3票、评分2.278），应按图像评分优先、票数破同分选无语言图（树林图2票、3.334）。这是通用拟合，非原版算法已逆向。浅图同样合法，文字必须根据实际色场亮度切换，禁止只按滚动阈值固定白字。主操作与次操作图标也必须跟随前景色。
