# 首页复刻接管：测量、边界与家族树

## 构思与证据

直接以 Pictures/REX 的 0138/0139/0140 原始 PNG 和 0142 视频为视觉事实。
旧 239 与交接词存在相互矛盾的结论，不作为硬约束。
当前卡为用户明确指定的首页视觉接管，不是后端 P15-B。

坐标：参照 1170/3=390pt，设备 1080/2.75=392.73dp；不把高度分别拉伸到相同大小。
原始数据/API 响应和探索图片暂存 build/p237_analysis，最终真机证据归 docs/evidence/p237/home-takeover/。

已确认的勘误：

- 0139 的文字和点仍白色，0140 连 hero 文字也变黑，旧的 S=110 切换和 hero 永不切换均错误。
- 0138 的海报相对原图约 1.14 倍中心放大；原尺寸直接铺满会使树木和倒挂人物错位。
- 初始渐变宽跨海报下半，不是 0.55→0.65 的狭窄遮罩。由逐行全宽残差反推透明度。
- 三帧空白区域 RGB 约 (28,10,9)、(128,118,123)、(200,195,203)，滚动约 0/181/313pt。
  它们与一次线性颜色混合 S/390 相容，无需五段样条和第二次 alpha 淡出。
- 0140 顶部已经是人物画面而非森林海报，不能把它全屏差分当作同素材静态样本。
- TMDB 中文 logo /bWKBEivoIiytdjTuWZ3O2ZDjYam.png 与参照相符；旧查询只取第一个中文变体。
- 磁盘缓存把透明 PNG 重编码 JPEG；页间共享异步图状态；加载回调 true 被当作缺图。

## 规划与自然家族树

沿用已有边界，新增文件进入 home 子目录，而不把页面再堆成一个函数：

```

ui/design/TmdbImage.kt            图像原始字节缓存、透明度保留、统一加载
ui/design/home/HomeAtmosphere.kt  单一背景混色、对比色和遮罩参数（纯视觉策略）
ui/design/home/HeroPage.kt        每页独立图片资源与文字布局
ui/design/HeroCarousel.kt         pager与当前页环境回报、指示点
ui/design/DiscoverPage.kt         模块布局与滚动状态
ui/design/CapsuleNavBar.kt        导航布局与玻璃轮廓
ui/design/home/NavGlyph.kt        可着色矢量导航图标
```

保持真实媒体/评分数据。无来源评分不编造。保留现有四个 tab 的功能路由。
不改签名、不卸载、不清应用数据、不碰后端或播放器 Surface。

## 闸门与验证

环境：显式 JAVA_HOME；JDK17 的 Windows AF_UNIX connect 失败，通过进程参数
`-Djdk.net.unixdomain.tmpdir=C:/Android/no-unix-sockets` 使 PipeImpl 安全回退 TCP。
不修改全局系统配置。基线 assembleDebug 成功、adb -r -t 成功，桌面重建后的 p12c 5/5 通过。

验收：同素材首屏、约180dp、约313dp、亮素材、横向切页、资源库/在看回归。
只对同素材区域报像素差；文字/卡片锚点独立报告；系统状态栏、不同媒体和缺源评分单列。
不以一条像素列或一张拼图宣称“像素级完成”。

## 真机首轮修订

- 原始 PNG 为 Display P3，所有色差报告先转换 sRGB。红色 logo 原素材本身正确，不调色。
- 旧字号表不等于截图实测：meta 可见字高 12.3pt、简介 11pt、节标题 14.3pt。
  Android 上按可见字高校准到 14sp/12sp/16sp，节头22dp + 间距12dp。
- 原始图最下10%算术均色实际 (19,5,6)，旧文“30,6,6”不成立。
  改为下15%在线性光空间平均，避免暗部编码均值压黑；不按影片硬编码颜色。
- 首页默认发现；导航按参照“发现/我的/资源库/设置”排序，映射既有页面。
  既有在看页通过“继续观看”右箭头进入，保留功能。
- 导航背板增加 home/NavigationBackdrop.kt：仅记录 Compose 内容绘制层，在导航范围重绘并模糊；
  不截播放器 Surface、不读回 CPU、不保存用户屏幕。图形和文字叠在背板之后。

## 动态首页增量设计（先于实现）

用户确认海报随日变化，静态展示后会播放预告片，下拉时封面放大。
逆向字符串证实自动播放/声音/首页封面/轮播数据可配置，不含可验证的延迟或缩放公式。
现有视频包含网络等待、滚动和横滑，不能把两次画面切换之差直接当作固定定时器。

数据：每次回前台刷新同一份 trending/week，hero 取前10，趋势模块复用响应；
刷新失败保留已显示内容并显式报告失败。图片元数据缓存限15分钟；成功视频结果限15分钟。
不按日期随机挑影片，不硬编码影片ID，不把 YouTube watch URL 当成媒体文件。
TMDB /videos 提供的是真实外部平台ID；优先官方 Trailer，中文/英文回退；
通过官方 YouTube IFrame API 播放，禁止抓取或假造直链。播放器在本页、前台、hero可见、
pager停止时才存在；默认静音，提供声音按钮。两秒是用户描述的目标初值，不声称逆向实测。
无预告片/禁嵌/网络失败都保留海报并有可见原因；不触及本地影片播放器或后端Surface。

下拉：LazyColumn 顶端未消费的手指位移驱动阻尼拉伸；松手用弹簧回位。
图片和视频共用同一个顶端锚定的变换，文字随封面底缘平移；正常向上滚动仍走列表。
参数单独归位，标明近似值，待连续拖拽录屏校准。

增量家族树：

```
tmdb/trailer/TmdbTrailers.kt        /videos请求选择、限时缓存、失败原因
ui/design/home/trailer/
  HeroTrailer.kt                   展示延迟、前后台/可见性、失败状态
  YoutubeTrailerView.kt            官方iframe播放、静音、代理与释放
ui/design/home/HeroPullZoom.kt      下拉阻尼/回弹与共享缩放参数
tools/home/analyze_recording.py     ffmpeg抽帧和逐帧差，输出可复算时间戳
```

验证闸门：构建成功；真机实时候选快照；两秒海报阶段与真实播放/失败事件；
前后台/横滑/滚出时播放器释放；下拉截图显示缩放且松手归位；既有导航可达。
若真实平台视频不可播，必须记录实际平台错误，不能以静态截图宣称动效验收通过。

## 播放崩溃后的采样边界修订

K40 播放确认后稳定复现 RenderThread 的 GLFunctorDrawable/SkSurface 崩溃；
导航范围 clip 不能阻止包含 WebView 的父 RenderNode 被离屏重放。
NavigationBackdrop 改为管理多个安全来源层：发现页只注册环境底色与非 hero 内容模块，
hero（含平台 WebView）始终直接绘制，不进入任何导航采样层。其他纯 Compose 页可整页注册。
来源随组合退出释放，按各自根坐标平移重绘；无需截图或 CPU 读回，也不关闭视频硬件加速。

## 用户选择预告片（最新产品约束）

默认仅图片，不请求 /videos 或 YouTube。设置→首页提供“首页预告片自动播放”开关，
说明需要能连接 YouTube；用户显式开启后持久保存，关闭即释放视频。
home/HomePreferences.kt 只管理此偏好；home/HomePreviewSetting.kt 只绘制设置行。
HeroPage 在开关关闭时不组合 HeroTrailer，环境色上报不受开关影响。

首页海报卡的点击使用 home/HomeTitleSheet.kt 展示已取得的真实片名、年份/类型、
TMDB 评分与简介，不把 TMDB 条目伪装成本地可播放文件。
文字/卡片精校只落首页：竖卡104×156dp、间距12dp；继续观看标题12sp/信息11sp，
进度轨2dp并内缩。用户要求的浅淡取色以28%中性页面色洗色作为本轮真机验证值。

## 顶部视频条的根因与修复

真机原生 WebView 已量到1080×1609px，但默认 WRAP_CONTENT 使 Chromium 的 vh/%
按零文档高度计算；iframe 的 y=-110.45、height=220.91 CSS px，于是只露顶部一条视频。
给原生 View 显式 MATCH_PARENT 后，iframe 高度恢复585.09 CSS px。
再以 fixed viewport 裁掉溢出，文档/视窗统一为392×585 CSS px，防止宽iframe扩大布局视窗。
16:9画布保持比例并以1.35倍中心裁切，降低片源自带电影黑边的影响。
1.35是本次设计参数，不是REX逆向值；任意片源的黑边与构图仍可能不同。

最终真机连续58秒录屏逐秒检查，视频完整覆盖封面；另外横滑确认第二部影片播放，
离开发现页有released事件。非发现页补statusBars inset，避免页标题顶入系统时钟。
正式记录及限制见 docs/evidence/p237/home-takeover/status.md。
