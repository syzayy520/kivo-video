## §3 环境色机制（重写核心，§零 E1–E5 的裁定）

### 3.1 v5 病根

环境渐变块是**独立 grid item 包裹 hero**（1.5 屏高），把全部节推到 1266pt 之后
→ hero 与首节之间出现一屏多空的"空洞灰底"（p237-v6top.png 即此态）。

### 3.2 重写后的层序（自下而上）

1. `AnimatedGradientBg`（正常页底，不变）；
2. **环境层**：视口固定的平色层（`ambient` = 海报底缘色 × 遮罩补偿，见 §4.1），
   alpha = `1 − min(scrollPx / fadeRangePx, 1)`，fadeRange = 420pt
   （裁定：E4 scroll 397/502 已全亮 ⇒ 完成点 ≤ 397；E3 scroll 0 全程平色 ⇒ 起点为 0；
   「hero 滚出(585)即恢复」自然满足；420 为完成点上限，装机后色带采样校准）；
3. `LazyColumn` 内容（hero 从 y0 开始，继续观看 header ~600 紧随 hero 585 之后——E1 同位）。

### 3.3 明暗自适应

`ambientDark = luminanceBelow(poster) < 0.55`（遮罩补偿后）：
首屏文字（节标题/卡标签/圆点/徽章数值）与导航玻璃、状态栏图标全部黑白自适应。
轮播滑动中：ambient = 当前页与邻页颜色按 pager offset 插值（t16–t21 整屏随划渐变实证）。

## §6 最终机制（v13/v14 修订，2026-11-08 用户逐帧验收后定稿）

> v5-v12 的「海报羽化 + blur(art×scrim) 背景层 + 渐暗遮罩」方案**全部废弃**——
> 双层渐变互相露底（v8-v11 反复踩坑），且遮罩把海报下部压黑、与真实底缘色
> （用户实测灰白）形成割裂。用户裁定最终结构（IMG_0142 对照播放器 + 0138/0139/0140 同构）：

**层序（自下而上）：**
1. **海报原色全画**（2:3 铺满，fy 0-1.0）——**不加遮罩、不加羽化**，下部保持原色
   （灰白海报下部灰白、黑海报下部黑——0138/grid_01 实证）；
2. **环境色遮罩盖在海报外层（上层）**：α 0（fy≤0.79）→ 1.0（fy 0.81）→ 1.0（1.0）。
   实色区从简介文字上缘（fy 0.81=474dp）开始：海报下部内容（0138 里艺术图自带的
   英文标题 fy 0.82-0.92）被完全盖住（Rex 实证不可见），海报底边同埋——
   「海报底边一条线」从机制上不可能出现；logo 区（fy≤0.785）完全透明不受影响；
   颜色 = mix(底缘色, pageBackground, t(S))，随滚动向页底过渡；
3. **下缘场** [585, 1100dp]：与遮罩同色同源（585 处无缝相接），平色 + 底部 29% α 渐隐；
4. 文字/logo/徽章/圆点全部画在遮罩之上。

**关键参数（帧实测）：**
- 环境色 = 海报底缘 10% 行平均色，**无遮罩补偿**（0138 场顶 (28,10,9) ≈ 原图底缘 (30,6,6)）；
- t(S) 分段线性：(0,0)(182,0.49)(301,0.81)(502,0.85)(900,1)——0138 全暗/0139 淡紫
  (129,119,123)/0140 近白 (202,197,204) 三态夹逼；
- 海报 = /images 第一张（gAgWJhUS 与 Rex 0138 同图实证；**不做 vote 排序**——API 缺省
  顺序即 Rex 所用）；hero 标题 = TMDB logo（zh→null→en），fy 0.59-0.785 限高 115；
- hero 组前景黑白 = 环境色亮度 <0.55（0138 暗→白、灰白→黑，整页不变）；
  chrome 组（节标题/卡标签/圆点/导航）= 暗海报且 S<110dp 白、否则黑
  （0138 白/0139 黑夹逼；亮海报恒黑）。

**已知偏差（数据源限制，非实现缺陷）：**
- hero 标题 logo：TMDB /images 的 zh 变体 =「生化危機+RESIDENT EVIL」，Rex 用的是
  「生化危机/爆发夜」变体（/images 未提供）——同为红色 zh 标题、同区同尺寸级；
- 徽章行仅 TMDB（IMDb/烂番茄/豆瓣无公开数据源，缺源不渲染）。
