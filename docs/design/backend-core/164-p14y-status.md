# 164 · P14-Y 验收：账建起来了，而且它真的会响

- 日期：2026-10-31
- 前置：`163-p14y-design.md`
- 结论：**观测层成立**。七轮真机（5 自然 + 2 对照）里，自然轮零事件、
  对照轮各记下一笔 —— 这说明"零"是钟真的没跳，不是仪器不响。
  行为一层没动（门的契约还在 P13-S/AB 那里），所以那笔大修正**仍然会被还掉**，
  只是现在能说出它是什么了。

---

## 一、七轮（4K30 60 s / K40 / 5000 ppm 注入）

| 轮 | 门 | `rebases` | 最大单笔修正 | 不连续事件 | `offset` | 最大那笔的 kind |
| --- | --- | --- | --- | --- | --- | --- |
| r1 | 开 | 49 | 5.20 ms | 0 | 0 | — |
| r2 | 开 | 48 | 5.19 ms | 0 | 0 | — |
| r3 | 开 | 48 | 5.19 ms | 0 | 0 | — |
| r4 | 开 | 48 | 5.19 ms | 0 | 0 | — |
| r5 | **关** | **0** | 0 | 0 | 0 | —（领先量涨到 288.26 ms） |
| c1 | 开 | 40 | **80.02 ms** | **1** | **+120.00 ms** | `position_step` @ 20.00 s |
| c2 | 开 | 24 | 5.20 ms | **1** | **−33.60 ms** | `backward_clamped` @ 20.00 s |

自然四轮的最大单笔都在 5.2 ms（迟滞带 + 一帧以内），与 P14-X 的"正常轮"逐格同量级。

## 二、正向对照：那笔台阶被完整记下来了

c1 在第 20.00 s 注入一次 +120 ms 的位置台阶：

| 字段 | 值 | 说明 |
| --- | --- | --- |
| `kind` | `position_step` | 落在正常分支、没有标志位的那一类 |
| `wall_delta_ns` | 33.44 ms | 这一帧墙走了多少 |
| `raw_delta_ns` | 153.44 ms | 设备给的位置走了多少（120 + 33） |
| `step_ns` | **120.00 ms** | 位置实际推进 − 墙钟推进 |
| `lead_before / after` | 一致地相差 120 ms | 成对出版，不用反推 |

**这一轮门仍然还了它**：`drift_max_correction_ns = 80.02 ms = 120 − (45 − 5)`。
换句话说，P14-X 那笔 146.75 ms 的**形状**第一次在真机上被完整复现并解释：
一次位置台阶 → 领先量跳一段 → 门按"漂移"一次还清。

## 三、反向对照：−120 ms 只记了 −33.6 ms，这是对的

c2 注入 −120 ms：位置往回跳 120 ms，被第二道倒退钳制按住了。
于是"位置实际推进"是 0，`step = 0 − 33.44 = −33.44 ms`，账上只有这一笔。

`raw_delta_ns = −86.6 ms` 原样留在证据里，但**不进 `offset`** ——
钳制是"拒绝这个输入"，位置确实没动；把被拒的 86 ms 也算进领先量，
等于替设备把那一跳认了下来。这条写在这里，免得后来者以为少记了。

## 四、判据被自己的数据改了一次

P14-Y 跑第一遍时，**X4 把 c1 判红了**：它数"钟事件"只数
`extrapolated_frames / monotonic_rejects / jump_rebases` 三个计数，
而 `position_step` 不在里面。判据把"有事件"说成"没事件"，比漏判更糟 ——
所以 `/36` 起 X4 把 `stepped + clamped` 也算进去；
"够不够大"仍由 Y3 守（`|step| ≥ 修正 − (带+帧)`），这一层比 X4 更严。

这是本项目第二次栽在同一件事上（上一次是 P14-X 把校验器的引号写坏）。
**判据自己也得跑一次**，而且得跑在真机产物上。

## 五、诚实清单

- **一台设备**（K40 `b6e950ee`），仍是 4K30，没拍 4K60 60 s。
- **自然运行 0/5 没重现 146.75 ms**：它本来就不是每轮都有（P14-X 是 1/4）。
  所以"机制成立"靠的是注入对照，不是自然复现 —— 这两件事不能互相替代。
- 对照是**注入**的台阶，不是设备自己跳的。它证明"记账与归类正确"，
  不证明"设备的台阶都长这样"。
- c2 的 −86 ms 被钳制拒绝，**没有进账**（理由见 §三）：这是设计选择，不是遗漏。
- 本卡**没有**改变门的任何行为：`drift_rebases` 与 `max_correction` 的可比性
  与 P14-X 完全一致；"要不要停止还台阶"仍是下一张卡的问题。
