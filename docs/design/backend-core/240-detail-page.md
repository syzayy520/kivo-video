## §1 页面结构（自上而下）

```
幕布幕布图（原色全画，标题烙印在图内）      ← 环境色遮罩只盖幕布下部（复用 239 §6 机制）
  meta（类型 · 日期 · 地区/集数）
  简介（2-3 行，左对齐）
  徽章行（有源的源才渲染）
  主操作行：观看胶囊钮 + (+收藏/♥待看) + ⋯
——幕布底缘自然过渡到浅色页面——
  演职员行（横滑：头像+名+角色）
  分类 chips
  预告片卡（/videos，有 trailer 才渲染）
  剧照行（/images backdrops，有图才渲染）
  媒体信息卡（本地库文件：清晰度/容量/码率/源名；无本地文件整卡隐藏）
  片源 logo（有源才渲染）
  相似作品列表（/similar）
```

**数据域**（全部 TMDB 公开 API，key/代理复用既有链路）：
- `/movie|tv/{id}`：meta/类型/简介/评分
- `/videos`：预告片（官方 trailer，zh 优先）
- `/credits`：演职员（cast 前 10）
- `/similar`：相似作品
- 本地媒体信息：WatchStore/媒体库按路径匹配（分辨率/大小/码率/来源名），匹配不到隐藏整卡。

## §3 实现要点
1. 幕布高：与首页 hero 同构（585dp）——E1 幕布原色，页面下部浅色由幕布底缘自然过渡
   （环境色遮罩只盖幕布下部，页面背景 = pageBackground）。
2. 主操作行：胶囊钮文字 = 有集数「观看第1集」/ 电影「观看」/ 加载中显示原因（G9）；
   副钮动作接入 WatchStore（收藏/待看状态持久化）。
3. 演职员/预告/剧照/相似：TMDB 无数据时**整节隐藏**（不渲染空壳）。
4. 媒体信息卡：清晰度大字取本地文件（HDR10/DV/SDR），容量/码率来自 MediaStore，
   源名+绿勾=来源库；无匹配文件隐藏整卡。
5. 返回钮、状态栏、导航玻璃复用首页既有组件。

## §5 真机实测修正（2026-11-08，P3 收口；**本节覆盖上文冲突处**）

v1 稿的 §1 节序与 E3/E6 锚点是按 detail_03/04 的**深色变体**抄的，且把 y 值错配到
不同元素上。真机首轮渲染 + 四帧逐行重测后，以下口径替换：

### 5.1 权威几何（dp，390×844 参照系；四帧一致）

| 元素 | 上沿 | 下沿 | 高 |
| --- | --- | --- | --- |
| 幕布艺术图 | 0 | **507** | 507 |
| meta 行 | 521.3 | 533.0 | 11.7 |
| 主操作行 | **552.3** | 597.3 | 45 |
| 简介 2 行 | 616.3 | 641.7 | 25.4 |
| 徽章行 | 658.7 | 668.7 | 10 |
| 下一节标题 | 720.7 | 737.0 | 16.3 |

**节序（帧为准）：幕布 → meta → 主操作行 → 简介 → 徽章 → 各节。**
v1 §1 写的「meta → 简介 → 徽章 → 主操作行」作废——按它实现会让徽章叠在简介上。

### 5.2 作废条目

| v1 条目 | 作废原因 | 替换口径 |
| --- | --- | --- |
| E1「无遮罩压暗」+ §1「环境色遮罩只盖幕布下部」 | 两条互斥；实测把幕布下半压成奶白（可见底缘 345.8 vs 507） | **不铺色遮罩**；仅在幕布最后 90dp 做「艺术图→页面底色」淡出 |
| E3 meta「类型 · 日期 · 地区/集数」 | 帧实测 meta 无类型；日期为中文格式 | `日期 · 地区 · 片长/集数`，例：`2026年8月19日 · 中国大陆/中国香港 · 2小时40分钟` |
| E6 y 区间 538–557 | 该值是简介行位置，非按钮 | 552.3–597.3，钮高 45 |
| E13「竖列表」被实现成两列网格 | 网格把 2:3 海报裁成横版 | 单列竖排：海报 92×138 + 右文 |
| §3.2 主钮文案「观看/观看第1集」 | 帧里无本地资源时钮面直接显示原因（G9） | 无匹配资源 → 钮面文案 = 原因，不做「假按钮 + toast」 |

### 5.3 主题口径

参照系含深/浅两个变体（movie_05 近黑底、movie_06/09 浅底）。本应用为浅色主题，
**对齐浅色变体**：艺术图淡出 → 页面底色 `pageBackground` → 正文 `textMain`。
文字**不压在艺术图上**（帧里 meta 起就在幕布之下），因此不需要按环境色算前景色——
这一条同时消除了「亮海报 → 白字不可读」的整类故障。

### 5.4 与参照的**故意**差异

| 项 | 参照 | 本实现 | 理由 |
| --- | --- | --- | --- |
| 地区写法 | `香港` | `中国香港` | 地区标注规范 |
| 幕布素材 | 专用 key art（0.769） | TMDB 海报 2:3（Crop 7%/边） | 无 key art 资产；海报自带标题烙印，可满足 E1 意图 |
| 徽章源数 | 六源 | 仅 TMDB | TMDB 不提供其余源的分值；E5「有源的源才渲染」 |

### 6.4 色场结论（二轮实测修正 §5.3）

- 参照的页面底色 **= 艺术图下部色**，因此幕布**不铺任何遮罩**（旧版首页曲线起点 47% 会把标题区洗白，
  这是首轮「不像」的根因）。
- 页面底色仍按首页机制 `lerp(环境色, pageBackground, 滚动dp/390)`，但**去掉首页那 28% 提亮**——
  详情页要求「页面色 = 艺术图色」才能无缝；首页提亮是为了内容区可读，详情页滚动后自然转浅，无需提亮。
- 文字色按 `HomeAtmosphere.lightForeground` 阈值翻一次，不逐帧重算。
