### 3.3 无障碍（**设计建议**——参照素材无 a11y 证据，按 Android 惯例补）

- 全图 contentDescription（海报=标题；图标钮=动作名）；
- 触控等效 ≥48dp（Ø50 圆钮达标；nav tab 补最小尺寸）；
- 焦点顺序 = 视觉序（TalkBack 线性走查）；标题行 heading 语义；

## 4. 关键任务流程及异常处理

| 任务流 | 路径 | 异常分支 |
| --- | --- | --- |
| T1 本地看片 | 发现 hero/卡 → 播放器 | 权限拒绝→引导页；缩略图失败→🎬占位；起播失败→G9 reason+重试 |
| T2 网络源看片 | 资源库→SMB/Emby→表单→浏览→播放 | 连接失败=表单内 reason；硬解失败→软解回退带 reason（G9）；播放中断网→error 行 |
| T3 下载 | 资源库/浏览行 → 下载 → 通知 → 媒体库 | 网断→Range 续传（✅225）；存储满→通知 reason |

| T5 投屏 | 播放器→投→sheet→设备→渲染 | 扫描空→文案；投失败→reason（✅230） |

## 5. 逐项优化与增强（格式：问题→证据→措施→保留→位置→验收→优先级）

1. **评分徽章行缺失** → grid_02 帧 hero 与详情页核心信任元素（IMDb/TMDB/豆瓣徽章）→ 接 TMDB API（标题+年份匹配，缓存到本地 JSON）→ 保留：徽章规格帧测（Ø~10 高/数值 13pt）→ `ui/design/RatingBadges.kt` + `tmdb/TmdbClient.kt` → 验收：本地片名匹配出徽章（或明确隐藏），无网不崩 → P0，风险=TMDB 需 API key 与网络（缺 key=整行隐藏，可接受）。
2. **继续观看无进度** → grid_02 帧"看到 01:57"+进度条是 REX 信任核心 → 播放退出时存 {mediaId: positionMs}（JSON 持久化，同 231 模式）→ 保留：两种形态（横滑卡/整行玻璃卡）+ 进度条永远在 → `stats/WatchStore.kt` + ContinueCard 接线 → 验收：播 30s 退出，发现页卡片显示看到位与条长 → P0，低风险。
3. **详情页缺失（点海报直接播）** → §6.4 结构 176 键 + 22 帧在手未测 → 新详情页（海报+标题+日期+评分行+直接播放主按钮+简介位）→ 保留：黑鹊帧布局关系（未测帧只取结构不取参数）→ `ui/detail/DetailActivity.kt` → 验收：海报→详情→播放全链，帧对照 → P0，中风险（22 帧未测量=先结构后参数）。
4. **媒体库未重铸** → lib_01/lib_02 帧（全屏铺底+浮钮组+胶囊筛选入口）→ MediaLibraryActivity 重铸：网格铺底 + 返回/排序浮钮 + 私密区浮钮 → 保留：全部帧测值 → `library/MediaLibraryActivity.kt` → 验收：并排对照 lib_02 → P0，低风险。
5. **图标是 emoji 代理** → 帧里是自绘图标（头像/人形/保管箱/齿轮）→ 换 vector 资产（自绘 4+2 枚，几何对齐帧）→ 保留：tab 结构与选中态 → `res/drawable/` → 验收：与帧并排无违和 → P1，低风险。
6. **设置全集缺失** → set_a/set_b 帧 + strings（每项有解释脚注）→ GroupedList 补组：播放（明文传输/解码/缓冲）/ 字幕 / 数据管理（清缓存真开关）/ 关于 → 保留：59pt 行+脚注"敢解释" → SettingsPage → 验收：每组真实生效（开关改的是真状态） → P1，中风险（数据管理要接真实逻辑）。
