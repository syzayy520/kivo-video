## 一、改了什么

| 位置 | 改动 |
|---|---|
| `DiscontinuityLedger::note()` | 跳变那笔记下"被丢掉的量" `raw_delta − wall_delta`，取 **|·| 最大**、**带符号** |
| `drift_discontinuity`（报告） | 多一格 **`jump_max_ns`** |
| `av_drift.sync_verdict` | 有过跳变且领先量在界内 ⇒ **`unknown`**（不再说 `av_synced`） |
| 判据 | **AF1**（这一格必须能被账解释）/ **AF2**（跳变轮不许说同步） |
| 单测 | `p14y_discontinuity_tests` 加 t10（6 条断言：绝对最大、符号、只认跳变、reset） |

**`unknown` 只在"本来会说 `av_synced`"的地方生效**：领先量本来就超过一帧时，`clock_off` 是有证据的
结论（那 1 帧是真量到的），不该被跳变盖掉。这是设计里的选择，不是遗漏。

## 三、这一卡最意外的一条：999 ms 那轮的跳变是**真的**

`p14af-999ms-b1` 的 `jump_max_ns = 1031.47` **不是注入的 999** —— 账里是三笔：

```
20.00s  position_step      step= 998.99  wall=33.11  raw=1032.10   lead 0.03→ 999.02   ← 注入
44.27s  monotonic_rejected step=   0.00  wall=32.47  raw=−999.00   lead 999.02→999.02  ← 真实事件
44.30s  jump_rebased       step=   0.00  wall=33.76  raw=1065.24   lead 999.02→999.02  ← 真实事件
```

44.27 s 位置先**倒退 999 ms**（被单调拒绝顶住），33 ms 后又**跳回 1065 ms** —— 净 +66 ms，
但那一跳被跳变分支丢掉，丢掉量 1031.47 ms 记进了新的一格。

**这是新字段第一次抓到"老版本看不见的东西"**：在 `/39` 上，这一轮只有 `jump_rebases = 1` 一个计数，
读者不可能知道被丢掉的是 1 秒还是 1 毫秒。现在它写在顶层。

顺带说清一件事：`jump_max_ns` **会把非注入的真实跳变也算进去**，这是对的（它就该记真实事件），
但读的时候不能假设它等于注入量 —— 这个格子的语义是"这一轮最大的一次位置重写有多大"。

## 七、诚实清单

1. **跳变轮只有两轮**（1500 ms 各一），`unknown` 这条路上没有更多样本。
2. **`jump_max_ns` 只留最大一笔**，不留"跳了几次、各在什么时候" —— 那要看 `recent`（环 8 笔）。
   超过 8 次之后环会滚，AF1 因此设计了"判不了"分支。
3. **`unknown` 不会覆盖 `clock_off`**（见 §一）。这是选择，代价是"跳变 + 真偏移"的轮次里
   读者仍要自己看 `jump_max_ns` 才能知道有跳变。
4. **全量 ctest 在设备取证并发时出现过一次 1 failed**（286 项里），随后两轮单独跑都是 286/286。
   **失败项的名字没留下**（`LastTest.log` 被下一轮覆盖），所以这一条只能记成"未查明"，
   不能写成"偶发"或"无关"。
5. **注入是假的**（同 `171` §八）：这一卡量的是"报告怎么说"，不是"真实重建时长什么样"。
6. **`/39` 及以前的 `av_synced` 不追溯**：那些是当时的真话，不是错账。

## 八、结论与下一张卡

`lead = 0` 现在有两种可分辨的说法：`sync_verdict = av_synced`（没有跳变）与 `unknown`
（有跳变、幅度见 `jump_max_ns`）。这是 P14-AC 之后同一族问题的第二次收口 ——
**每次都是"给一个数配一句使用条件"，而不是"把数改小"**。

下一张卡的候选（按我的判断排序）：

1. **`present_jitter` 只有分位、没有位置**（`169` §九）：问不了"那 24 帧丢在哪几秒"。
   要回答它，报告得出版逐帧 `(pts, due, present)` 的抽样 —— 出版层改动，独立一张卡。
2. **at_time 档那条恒等式差 3 帧**（`169` §三 边界段）：`wall − media = −lead` 在 `surface_at_time`
   上差 99.948 ms，原因未查。它与 P14-AA 的 `span_basis` 是同一块。
3. **负方向的大跳变**（−1500 ms）：倒退钳制会先按住它，机制比正方向多一层，从来没测过。
