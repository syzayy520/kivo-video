## 0. 产品原则（评审 E 终稿六条，全体验收的最高层）

1. **不破坏时间轴**：原始对白的出现与消失时机不被翻译过程擅自改变（DEC-07 v2）；
2. **不影响播放**：AI 的异常、性能竞争、资源消耗不让播放器变不可靠（8 场景 + 对照容差）；
3. **不丢失结果**：进程中断、切片、重启后已完成结果可恢复（journal 事件模型 + manifest 意图）；
4. **不误导用户**：就绪范围、未译字幕、翻译质量有清晰诚实的表达（DEC-11 v2 稀疏感知口径）；
5. **不强迫用户操作**：用户选轨偏好受尊重（N2/E10），模型与缓存管理尽量自动化；
6. **不破坏播放器审美**：AI 自然融入播放器，不变成 AI 工具界面（禁止 AI 味装饰，对齐设计铁律 V2.0）。

## 1. 词汇表（唯一口径；评审 F10：三层「关闭」混用是本轮硬矛盾）

| 词 | 用户语义 | 技术语义 |
|---|---|---|
| **暂停** | 临时停下，可继续 | 任务态 PAUSED_*，检查点保留 |
| **关闭（中文字幕）** | 移除当前 AI 轨，保留进度 | 轨道移除 + 任务转「已停止」；再次开启 = 续译 |
| **删除** | 清掉这部片的翻译进度与缓存 | journal + 缓存 + 检查点清除（活动文件保护） |
| **启用 AI 字幕翻译**（设置总开关名） | 功能是否可用 | 关闭 = 入口灰显 + 任务暂停保留，**不删数据** |

用户文案禁用词：生成、任务、执行、取消（v2「停止翻译」在服务范式下统一为「关闭中文字幕」——评审 D1）。

## 2. 范式与首次体验

**服务开关，不是任务**：用户侧只有「**中文字幕：开 / 关**」一个动作 + 详情 sheet 里的次级操作。
入口主行不出现「生成/正在翻译」字样（中文已上屏后「准备中」会让人困惑——评审 F9）；首块前显示
「正在准备中文字幕」，首块就绪后显示「已就绪至 mm:ss」（连续已处理口径）。

**首次开启一次性说明**（可关）：本地运行 · 字幕不出设备 · 模型安装可能需要网络（G15 修正）·
耗时与片长相当，视设备温度而定（F11：不写死 30-40 分钟）· 持续发热耗电。

**信任锚点**：轨道名「AI 中文（机器翻译）」自带诚实定位；完成卡附「可同时显示原文对照」可操作入口；
质量抽检数据**只进诊断模式**（E27：不让用户把测试集数字误读为"这片 96% 准"）。

## 3. 状态体系：四层模型 + 完整状态总表（评审 E12/G12 + 自查 N10）

四层：**功能层**（启用/禁用）· **任务层**（十态）· **环境层**（缺模型/校验失败/存储不足/热控/低电量/
内存压力）· **展示层**（AI 轨挂载/未挂载/中文就绪/落后于播放）。统一状态解析器
（`EntryStateResolver` 纯函数）按优先级合成 UI 展示态。

**任务层十态**（总表；TalkBack 列为实现时逐条落）：

| # | 态 | 进入条件 | 入口投影（主行/副行） | 可用操作 |
|---|---|---|---|---|
| 1 | 待开始 | 可用且未开启 | 中文字幕 / 开启后 AI 翻译为中文 | 开启 |
| 2 | 准备中 | 校验字幕/模型/存储 + 引擎初始化（含首次全量 SHA） | 正在准备中文字幕 / 校验模型与字幕 | 关闭 |
| 3 | 翻译中 | 任务运行且未达领先窗口 | 已就绪至 01:21:30（连续已处理终点）/ N/M 条 | 暂停 · 关闭 |
| 4 | 已暂停（手动） | 用户暂停 | 翻译已暂停 / 已完成 N/M 条 | 继续 · 关闭 |
| 5 | 已暂停（系统） | 热控/低电量/存储不足/内存压力（原因入副行，分别维护） | 已暂停（设备温度较高，恢复后自动继续）/ N/M 条 | 关闭 |
| 6 | 已中断 | 进程被杀后重进（manifest 说运行中） | 翻译已中断 / 已完成 N/M 条 · 继续 | 继续 · 关闭（**不自动续译**，F4） |
| 7 | 已停止 | 用户关闭中文字幕 | 已停止 · 已完成 N/M 条 | 开启（续译）· 删除 |
| 8 | 部分完成 | 无 PENDING 但存在 FAILED_FALLBACK | 中文字幕已就绪 · N 条保留原文 | 重试失败行 · 关闭 |
| 9 | 已完成 | 播放头到片尾且无 PENDING（领先窗口口径自查 N6；提前翻整片则=无 PENDING） | 中文字幕已就绪 | 显示模式 · 删除 |
| 10 | 失败 | 引擎异常/模型错误且重试穷尽 | 翻译失败（原因非空）/ 重试或关闭 | 重试 · 关闭 |

**入口展示态**（解析器输出，优先级自上而下；评审 F2 修正版）：
功能关闭（灰显保可发现，点按引导去设置）→ 任务态 2-10 → 字幕条件（无字幕/仅 ASS/仅内嵌/含中文+逃生口/
非英语）→ 模型条件（缺模型/校验失败）→ **可用（happy path：中文字幕 / 开启后 AI 翻译为中文）**。
存储不足是安装旅程前置条件（北极星 §8），v1 不在播放入口占位（F2）。
互斥场景（已核实 PiP 存在）：另一片 PiP 翻译中 → 报进度 + 「切换任务」（F13 裁定）。

## 4. 进度表达（DEC-11 v2 + G13）

- **主指标：自播放头起连续已处理终点（hh:mm:ss，超 1 小时用三段式）**——LLM_TRANSLATED /
  RULE_TRANSLATED / INTENTIONAL_KEEP / FAILED_FALLBACK 连续，仅 PENDING 打断；
- 播放头落在空洞 → 显示「正在翻译当前位置，暂以原文显示」（落后态文案，F3）；
- 辅指标：已处理 N / 共 M 条（**cue 口径 = 装配后显示 cue 数**，DEC-07 v2）；「未译（保留原文）」
  单独一行（FAILED_FALLBACK 计数），与待译分离；
- 五结果状态（G13）：LLM_TRANSLATED / RULE_TRANSLATED / INTENTIONAL_KEEP / FAILED_FALLBACK /
  PENDING——完成卡与 trace 按此统计；
- seek 后重排 → 副行补「已优先翻译当前位置附近」；不显示剩余时间与百分比单指标；
- **落后态**（评审 E25 三方案）：倾向「原文回退 + 低干扰说明」组合——原文保信息完整（方案 A），
  状态变化经面板状态行说明（方案 C 精神），不给每条未译 cue 弹提示；中英跳变感知强度由真实影片
  设计稿判定（DEC-09，视觉稿任务清单）。

## 5. 暂停 / 关闭 / 恢复 / 重试

- 暂停（手动）：永不自动恢复；系统暂停：全部原因解除自动恢复（迟滞）；
- 关闭中文字幕：移轨保留进度；再次开启续译并明示「继续上次翻译 · 已完成 N/M」；
- 重试失败行：**加前后 2 条原文上下文重新翻译**（改变输入满足不变量；全在 user 段保前缀 KV）——
  v1 调度器能力，非二期；深层次编辑/术语表二期；
- 熔断禁用（连续 2 次 Native 崩溃）：设置页一键重新启用 + 诊断入口（评审 C1 分阶段表）；
- 换片：旧任务自动暂停保留；PiP 场景下任务继续（互斥场景写明，F13）。

## 6. 字幕显示模式（三选：仅中文 / 仅原文 / 中文 + 原文）

「同时显示原文」开关**挂在 AI 轨那一行**（不做设置页模式，避免双真源）；仅原文 = 用户选英文轨；
副字幕位置/字号/对比度出独立设计稿（DEC-09，三向空间博弈：顶部 cue/底部双行/刘海——评审 D5/E25：
这是设计任务不是验证任务）；v1 副字幕默认关；用户关闭双语后记住选择；
无障碍：副字幕对比度靠描边/底板达成（动态视频背景无静态 AA）；CaptioningManager 系统字幕偏好
尊重与否在设计稿阶段明确（E16/G17）。

## 7. 无障碍

- 状态传达不依赖颜色/斜体（文案 + 结构）；失败行纯原文零标记（DEC-05）天然友好；
- TalkBack：只播报**用户操作结果 / 完成 / 出错**（看片时屏幕阅读器不与影片音频抢——评审 F14）；
  就绪范围变化合并通知；十态播报文案 = §3 总表逐条落；
- 副字幕对比度 ≥ WCAG AA（靠描边/底板在动态背景上达成）；
- 尊重系统字幕偏好（字号/边缘/颜色，CaptioningManager）与否在设计稿阶段定。

## 8. 设置页分层 + 北极星

**常用**：启用 AI 字幕翻译（总开关，改名自 v1）· 字幕显示模式入口 · 翻译缓存占用与清空
（活动文件保护）。
**高级诊断**：模型状态与放置路径（v1 开发者模式）· BlockStats trace 开关 · 熔断禁用重置 ·
质量抽检结果（测试集口径，不面向普通用户——E27）。
**北极星安装旅程**（DEC-02 发布门槛，G33 状态机）：未安装 → 下载中 → 校验中（全量 SHA256 对可信
发布清单）→ 安装中 → 已就绪 + 暂停/失败/取消；完整校验前不进可用目录；临时文件与正式文件同文件系统。

## 9. 来源选择（评审 E23/G23：来源选择与轨道显示是两个操作）

- 多份英文 SRT → 「选择翻译来源」页：列文件名 + hash 后缀区分同名 + 轨道名；
- 开始后来源名保留在高级信息（「AI 中文来自：English.srt」防误认，E24 尾）；
- 翻译中源文件被替换：任务用启动时输入快照继续（不受影响）；下次开启检测到 hash 变化 →
  提示「源字幕已更换，旧译文不再匹配」（E24 场景表）；
- SAF content:// 先复制进私有目录再翻；内嵌轨提示「暂不支持」。

## 10. 二次观看场景表（评审 E24：用户使用最频繁的态）

| 场景 | 用户看到 |
|---|---|
| 缓存完整命中 | AI 轨自动挂载（只加轨）+ 按片源级最后用户选择决定是否选中（E10） |
| 缓存部分命中 | 恢复已有内容 + 继续翻译剩余（检查点续译） |
| 用户上次停止 | 「已停止 · 继续」 |
| 源字幕已更换 | 提示旧译文不匹配，提供重翻 |
| 原字幕文件被删 | 已生成中文字幕保留 + 来源状态说明 |

## 11. 用户旅程（验收走查）

① 面板见入口（含为何不可用）→ ② 条件检查（来源/格式/模型）→ ③ 开启（成本已告知 · 本地）→
④ **Preview Slice 首块就绪即建轨选中，立刻可看**（落点所在网格块 [播放头,+8)，E8）→
⑤ 观看中持续补全（连续已处理终点推进；落后时原文兜底 + 文案）→ ⑥ 中断/恢复（退出、暂停、热控、
进程被杀——journal + manifest 不丢）→ ⑦ 停止/完成（五结果统计卡）→ ⑧ 二次观看（缓存自动挂载）。

## 12. 完成状态卡（评审 E27/B22 修订：只放计数，不放成功率）

已译 N 条 · 保留原文 M 条 · 规则跳过 K 条（五结果口径）+ 「重试失败行」+ 「同时显示原文对照」可操作入口。
**未翻译 ≠ 错误翻译，分开统计。**

## 13. 线程与状态契约（评审 B 布尔/评审 F18）

后台翻译线程**只经 Handler(mainLooper) 单入口**写状态对象；状态机 = 纯 reducer
`(state, event) → (state, effects)`（JVM 可单测，技术文档 §2 TranslationStateMachine）；
播放页退出重建后从 Controller 恢复订阅。

## 14. 视觉稿任务清单（DEC-09，对照 rex 播放 UI 基准出稿后再实现）

① 入口全态真实状态稿（§3 全投影）；② 翻译进行中（不破坏面板布局）；③ 设置分层；④ 双语显示
三向空间博弈（顶部 cue / 底部双行 / 刘海）；⑤ **落后态视觉方案**（压暗/留白/回英文的观感取舍）；
⑥ 完成状态卡；⑦ 来源选择页。
