## 0. v1.1 相对 v1 的修订（以 REX 追加审计为准）

| 项 | v1 | v1.1 | 理由 |
|---|---|---|---|
| 面板底 | 纯黑 80% | 冷调烟熏渐变：#B80A0F14(72%) → #C20A0F14(76%)，RGB 10/15/20 | 打破“均匀实心板”；冷调让面板不属于纯黑贴纸 |
| 圆角 | 20dp | **16dp** | 追加审计撤回 20dp，保留 REX 实测 16dp，避免推翻已验收几何 |
| 边缘 | 完全不画线 | **仅顶边 1dp 白 7%，左右 24dp 渐隐**；其余三边不画 | 顶边受光是玻璃感细节，整圈线才是盒子感 |
| 阴影 | 28dp 纯黑 | 24dp，黑色 30%（spotColor 带 alpha） | 更柔，亮画面不出现脏边 |
| 行标题 | 95% | 90% | 72% 底上 6.8:1，减少刺眼 |
| 副题/分组头 | 55% / 38% | **68%** | 72% 底上 4.7:1；55% 在 72% 底只有约 3.9:1，不达标 |
| 数值 | 70% | 80% | 5.7:1，数字更像数据 |
| chevron | 45% | 55%（非文字，3.6:1） | 非文字只要求 ≥3:1 |
| 长文案卡 | 无 | 允许 A3 密玻璃 #CC0A0F14(80%)，副题 60% / 正文 58% | 仅用于两行以上解释的字幕样式/延迟卡 |

**结论：不以“把 75% 调低”来去黑板；以“冷调 + 渐变 + 去整圈描边 + 去内嵌卡 + 抬副文字白度”来去黑板，透明度只降 3 个点，对比度反而从 4.4 修到 4.7。**

## 1. 目标与非目标

目标：消除“实心黑板 + 描边盒子”观感，建立 Apple 级层次；同时修补比视觉更伤体验的三个交互缺陷（首响、步进误触、面板打开时控制栏自动消失）。

非目标：
- 不做真实背景模糊。视频层是 SurfaceView（`ui/PlayerSurfaceView.kt:17`），SurfaceFlinger 独立合成，Compose 拿不到其像素；`Modifier.blur` 只糊自身内容，`RenderEffect` 只作用于自身 layer，`Window.setBackgroundBlurRadius` 糊的是窗口背后。PixelCopy 抓帧方案经评估**明确否决**：mpv 把 ASS/文本字幕烧进同一帧，抓到的帧必然带当前字幕，作为背板会形成“糊掉的字幕影子”，且面板打开期间字幕继续变化而背板是死的；另有单帧约 9.6MB 内存、20–50ms 回读、HDR/DRM 偏色或失败、旋转/多实例要重抓等问题。除非视频输出改 TextureView（内核/呈现路径改造）否则不做。
- 不做全屏 scrim（旧治理 A4），只做面板外 20–30dp 的局部柔光。
- 不改 REX 已验收几何：轨道 6pt、图标 pitch 50、面板宽度 248 / 微调卡 357、锚点体系。

## 2. 黑板根因（已核实）

| 现象 | 根因 | 位置 |
|---|---|---|
| 一块实心黑板 | 面板底 = 黑 75% | `player/PlayerTokens.kt:50`（`panelSurface`） |
| 贴纸感 | 上半个面板再叠 8% 白光 + 1dp 白 8% 连续描边 + 18dp 黑影 | `player/PlayerGlassSurface.kt:39-67` |
| 盒中盒 | 微调卡外层 16dp 圆角玻璃，内部再套 10dp 圆角、黑 30% 内嵌卡 | `player/PlayerDetailCard.kt:118-124`、`PlayerTokens.kt:66` |
| 文字发灰 | 75% 底上 55% 白副题 → 纯白画面下对比度 ≈4.4:1（低于 4.5） | 见 §6 |

## 3. 材质规范

| 层 | 规格 |
|---|---|
| 面板底 | 冷调烟熏渐变：上 `#B80A0F14`(72%) → 下 `#C20A0F14`(76%)，RGB 10/15/20。**不用纯黑**——纯黑 = 黑板 |
| 顶部高光 | 白 3% `#08FFFFFF`，仅覆盖顶部 24dp（不是上半个面板） |
| 边缘 | **仅顶边** 1dp 白 7%，左右各 24dp 渐隐到 0；左/右/底边不画线。整圈连续描边才是盒子感根源 |
| 局部柔光 | 面板形状 `shadow(elevation = 24.dp, ambientColor/spotColor = Black 30%, clip = false)`；亮画面不出脏边 |
| 圆角 | 列表 16dp、微调卡 16dp（统一；沿用 REX 实测值） |
| 内嵌卡 | **删除**，组内不再套任何背景/圆角/描边 |
| 长文案卡（A3） | 仅两行以上解释性文案用密玻璃 `#CC0A0F14`(80%)，副题 60% / 正文 58%；普通行不用 |
| Toast | `#E60E0E10`(90%)、圆角 14、无描边、阴影 8、内边距 14×9、13sp；错误态文字前 6dp 琥珀点 `#FFB020` |

性能：仅“一次阴影 + 一次渐变填充”，与现状同量级；验收看打开 240ms 内掉帧 ≤1 帧、无 CPU 尖峰。

**材质法则（一句话）**：冷调 + 纵向渐变 + 单边受光 + 柔边 = 玻璃；均匀纯黑 + 整圈描边 + 内嵌盒 = 黑板。

## 5. 间距与密度（dp，4/8 网格）

双密度档，由 kind 选择（不是两套 UI）：

| 项 | Comfort（字幕/音轨/跳过/弹幕） | Compact（倍速/画质比例） |
|---|---|---|
| 左右内边距 | 20 | 20 |
| 上下内边距 | 8 | 4 |
| 头部高度 | 56 | 无头部 |
| 单行行高 | 56 | 42 |
| 双行行高 | 72 | — |
| 步进/开关行 | 64 | — |
| 行右内边距 | 16 | 16 |
| 分组头 | 上 12 / 下 4，缩进 20 | — |
| 组间分隔线 | 1dp 白 6%，上下各 4dp，缩进 20 | 无 |
| 组间留白 | 12 | — |
| 重置行 | 48，居中，无分隔线 | — |
| 滚动内容底部留白 | 64 | 8 |
| 圆角 | 16 | 16 |

Compact 保留 42 的原因：底栏锚点可用高度约 311dp，7 档 ×42 正好放下，保证“一眼看全 7 档”。

行内几何：无图标行文字从 20 开始；勾/chevron 一律在**行尾**（勾 16dp 白 90%、chevron 16dp 白 55%）；列表行不再放装饰图标。数值列固定宽 64、右对齐；−/+ 各 44×44 命中区（视觉 glyph 16dp）。

顶边受光线占 24dp 宽渐隐，与圆角 16 不冲突；`edgeGap 16` / `anchorGap 8`，面板不盖住触发控件。

## 6. 对比度（v1.1 口径：最坏情况纯白画面，取渐变最浅的顶边 72%；v2 见 §6.1）

面板底 `#B80A0F14` 合成到纯白 → 底色相对亮度 L≈0.083（纯黑 75% 底为 L≈0.050，但它的问题是“黑得没有层次”，不是对比度更低）：

| 角色 | alpha | 对比度 | 结论 |
|---|---|---|---|
| 行标题 90% | 0.90 | ≈6.8:1 | ✅ 正文 ≥4.5，且不刺眼 |
| 数值 80% | 0.80 | ≈5.7:1 | ✅ |
| 副题/分组头 68% | 0.68 | ≈4.7:1 | ✅（旧 55% 在 75% 纯黑底只有 ≈4.4:1，不达标） |
| chevron 55% | 0.55 | ≈3.6:1 | ✅ 非文字 ≥3 |
| 禁用行 38% | 0.38 | — | 豁免（禁用态） |

**规则（v1.1）：正文 ≥4.5:1、标题 ≥6.5:1、非文字 ≥3:1。** 允许调材质与渐变，不允许把副题降回 55%、把底降到 70% 以下——那是用可读性换“通透”，反而更像黑板。

### 6.1 v2 亮场让步（2026-11-20 用户拍板）

v2 面板底降到 62–65%，上表按 72% 底计算，已不适用。真机亮场实测（`docs/evidence/visual-polish/panel-v2/ACCEPTANCE.md` §8.3，视频 255）：

| 角色 | 实测对比度 | 65% 透光底上的理论上限 | v2 亮场判据 |
|---|---|---|---|
| 行标题 90% 白 | 4.91:1 | ≈5.2:1（纯白） | ≥4.5:1 |
| 副题 68% 白 | 3.75:1 | ≈5.2:1 | ≥3.5:1 |
| 组头 55% 白 | 2.80:1 | ≈5.2:1 | ≥2.8:1 |

- 原「亮场白字 ≥6:1」在 65% 透光底上**物理不可达**：即使文字为纯白，理论上限也只有 ≈5.2:1。暗场仍按 §6 的 ≥6:1 执行。
- 用户拍板：**保持 v2 透光，不改面板底与文字层级**，亮场按上表收口；若未来要求亮场正文 ≥4.5:1，只能提高面板不透明度或把文字提到接近纯白，二者都会牺牲 v2 的透光/层级。

## 7. 控件形态

- **步进行**：行高 64；标题 16/90%；数值 15 Medium/80% 右对齐宽 64；−/+ 无胶囊底、无内部竖线，仅 16dp glyph 白 75%；按下 glyph 后出现 32dp 圆形白 8%（90ms 进 / 140ms 出），行不缩放。
- **步进时机**：改为 `up` 触发；按下后位移 >8dp 或滚动开始则取消。长按 400ms 后 80ms/步，2s 后 60ms/步；到边界一次“拒绝”触感并停止。数值变化 100ms alpha crossfade；失败行内显示“调整失败”1.5s 后回真值，不弹全局 Toast。
- **开关行**：64 高；46×28、圆角 14；开=白 95% 轨 + `#1C1C1E` 旋钮；关=白 15% 轨 + 白 95% 旋钮；旋钮 240ms spring；整行可点。
- **选择行**：56/72；勾在行尾 16dp 白 90%；选中不加粗、不加底色；按下 6% 白 + 0.985 缩放（90ms 进 / 140ms 出）。
- **钻入行**：chevron 16dp 白 55%，行尾。
- **重置行**：48，14sp/68% 居中，上方 12dp 渐隐，固定底部（保留 FAIL-2 修复）。
- **禁用行**：整体 38%，副题原因保留。

## 8. 动效

| 事件 | 时长 | 曲线 | 属性 |
|---|---|---|---|
| 面板打开 | 240ms | `CubicBezier(0.2,0,0,1)` | alpha 0→1；translateY 10dp→0（顶栏锚点 −8→0）；**不缩放** |
| 面板关闭 | 160ms | `CubicBezier(0.4,0,1,1)` | alpha→0；translateY 0→6dp（朝锚点） |
| 钻入/返回 | 140/120ms | FastOutSlowIn | alpha + 4dp 纵向位移 |
| 行按下 | 90ms | FastOutSlowIn | 6% 白覆盖 + scale 1→0.985 |
| 行松开 | 140ms | FastOutSlowIn | 回 0 / 1 |
| 数值变化 | 100ms | FastOutSlowIn | alpha crossfade |
| 勾出现 | 140ms | spring(0.7, 500) | scale 0.8→1 + alpha |
| 开关 | 240ms | spring(0.85, 400) | 旋钮位移 |
| 滚动条 | 120/300ms | Linear | alpha |
| 内容空→有 | 120ms | Linear | alpha |
| 减弱动效 | 100ms | Linear | 只留 alpha，位移/缩放为 0 |

不做行错峰；不做假 blur 淡入。动效常量放 `PlayerPanelStyle.motion`，不动 `PlayerMotion` 全局值。

## 9. 滚动

- 顶部/底部 16dp 渐隐（离屏 layer + `DstOut`，透出面板底而非黑色），按 `canScrollBack/Forward` 显隐。
- 指示条：2dp 宽、右内 4dp、拇指高度 = `max(28dp, 可视比例×视口)`、白 30% 圆头；只在滚动中及停手后 600ms 显示。
- 溢出时下一行露出 8–24dp（内容高度不取整到行高）。
- 关闭 Android 12+ 过度滚动拉伸。
- 重置行上方 12dp 渐隐，滚动底部 padding 64。
- 面板钻入/返回时滚动位置归零。

## 12. 硬边界

禁止改动：面板行顺序与 tag、`SUBTITLE_PANELS`、`DRILL_KINDS`、`STEP_UNITS`、`SubtitleStyle` 属性表与持久化、导入 md5 去重、主次字幕互斥、删除确认、重置同源值、`panelRevision` 刷新机制、mpv 内核参数、ASS/纯文本渲染链路。

## 13. 验收口径（摘要，详表见审计）

## 18. 面板背景「抓帧 + 模糊」（2026-11-21）

补 SenPlayer 唯一还差的"磨砂"：面板玻璃**之下**铺一张当前画面的模糊图。

- **抓帧**：`mpv command("screenshot-to-file", "<cache>/panel-backdrop.jpg", "video")`（与截图按钮同通道）。
  用内核通道而非 `PixelCopy`：视频是 SurfaceView，PixelCopy 在部分机型/PiP 下会拿黑帧。
- **处理**：`inSampleSize` 降采样到 ≈480×270 → 三遍可分离盒式模糊（半径 clamp 3..16）。
- **绘制**：`playerPanelSurface(backdrop = …)` 在玻璃渐变**之前** `drawImage`，裁在圆角内；
  **不再额外叠白洗**（首版叠了 35%，亮场被推到 241，比对方还亮 —— 已删）。
- **时机**：面板打开时抓一次；`open=false` 即返回 null。同步命令，不每帧抓。
- **回落**：`backdrop=null` 时整层跳过，绘制与 §16 逐像素一致（Toast/投屏卡/截图钮默认不传）。
- **实测**：暗场面板 **114.0**（SenPlayer 117–120）；亮场 **234.7**（对方等价场景 218–226）；
  面板内平滑度 0.981 / 0.992（无锐边）。
- **如实说明**：亮场白字仍不可读 —— 与 SenPlayer 同量级，**持平不是解决**；要可读需按背景亮度切深色卡片（未做）。
