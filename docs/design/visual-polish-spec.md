# 视觉打磨规范（颜值门）

> 2026-11-17 ｜ 用户原则：**UI 颜值是第一直观印象，功能再好也抵不过颜值高的**。
> 与 `ui-quality-gate.md` 并列：结构/尺寸过门只是及格，**视觉不过门同样不算完成**。

## 一、颜值五要素（每页必须全部成立）

1. **背景有层次**：页面不是纯平色。顶部 `bgLavender` → 40% 处 `pageBackground` 的垂直渐变；深色态用 `washFill` 叠深。
2. **卡片浮起来**：白卡 `canvasFill` + `hairline` 描边 + **柔和阴影**（`shadow(elevation = 2.dp, shape, ambient = Black 6%, spot = Black 8%)`），圆角 **16dp**（大图卡 20dp）。禁止「白底+灰底」的分界线代替阴影。
3. **图片有质感**：所有封面统一圆角 **12dp**，叠 **1dp 白色 8% 内描边**；加载中用 `TmdbPlaceholder` + 由上至下的 4% 白微光，不用纯灰块。
4. **字体有三层**：页面标题 26–28sp Bold / 小节标题 16–20sp Bold / 正文 13–15sp Regular；**关键数字 30–32sp Bold**（今日小时、收藏数、在看数）。同级字号一致，不出现 14/15 混用。
5. **节奏统一**：模块间距 **20dp**、卡片内边距 **14dp**、卡片之间 **10dp**、左右边距 **13dp**。不允许出现 >48dp 的空白带。

## 二、加分项（kivo 差异）

- **大图叙事**：热门综艺/英雄区用全宽 16:9 + 底部黑渐变 55% + 白字标题，图片本身撑起画面。
- **玻璃导航**：底部胶囊 92% 白 + 2dp 阴影（API31 前无真 blur，用不透明度换取质感）。
- **能力高亮**：4K/HDR/10-bit 用 `accentGreen` 14% 底 + 绿字，让硬件能力成为视觉亮点（详情页徽章）。
- **按压反馈**：卡片按压 scale 0.98 + 180ms，减弱动效时 0ms。

## 三、验收方式（硬性）

每个页面必须产出「基准 | 当前」并排图（`docs/audit/golden/cmp/`），并由验收人逐条回答：
1. 背景是否渐变、是否有层次？
2. 卡片是否有阴影/描边、圆角是否一致？
3. 图片圆角与内描边是否统一？
4. 字号层级是否只有三层、数字是否突出？
5. 间距是否 20/14/10、有无大块空白？
六项任一为「否」→ 打回重做，不得进入下一批。

## 四、禁止

- 用「功能完成」代替「看起来精致」。
- 用纯色平铺、无阴影白卡、无圆角图片交付。
- 在未做并排视觉对比前宣称完成。
