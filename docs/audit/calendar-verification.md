# 日历页验收（时间维度补全）

> 2026-11-17 ｜ 设备 b6e950ee（1080×2400 / 440dpi）
> 触发：用户指出「周历只有 7 天，一年/两年/十年怎么办」——时间维度是逻辑问题，不是视觉问题。

## 一、结构

`我的` 周历（7 天摘要）→ 点任一日 / 环境头日历圆钮 → **独立「日历」页**（`CalendarActivity`）。

日历页：
```
返回 · 大标题「日历」· 今天
[月] [年]              ← 视图切换
‹  2026年11月  ›        ← 期间行，任意年切换
日 一 二 三 四 五 六
6×7 月网格（44dp 格）
当日摘要卡
```

## 二、时间维度（关键逻辑）

| 项 | 实现 |
| --- | --- |
| 年份范围 | `2000 .. 今年+1`，箭头 `coerceIn`，不越界 |
| 数据窗口 | 只读**当年**（1/1 起的自然日数，闰年 366），不写死 7/140/3650 天 |
| 跨年 | 月视图左右箭头自动进位/退位到相邻年；年视图直接切年 |
| 周起点 | **周日=0**，与 `WeekStrip` / `ProfileStats` 一致（否则整月错一列） |
| 无记录年 | 保留 12 个月格可浏览，下方补「{year} 年没有观看记录」 |
| 无记录月 | 保留网格，补「{month} 月没有观看记录」 |
| 整机无记录 | `hasRecords=false` → 整页空态（图标 + 引导，不画网格） |
| 闰年/夏令时 | 按 `Calendar` 逐日递增，不用 `/86_400_000` |

## 四、入口

1. 周历任一日期 → 带日期进入（该日选中）。
2. 环境头「编辑」左侧 36dp 日历圆钮（`contentDescription = "打开日历"`）→ 进入今天。

## 五、剩余

1. **整机无记录空态**：本机 10 年窗口内有记录，未触发；由 `CalendarPage` 的 `@Preview`（空态）覆盖，文案「追剧日历会在你看过或加入待看后出现」。
2. 年视图月内热力条是**月度总量单强度**（`yearMinutes` 只给月合计，不编造日粒度，KDoc 已标）。
3. 月摘要的片名依赖 `ContinueWatching.aligned` 最近 60 条，跨零点/≥95% 看完的片可能无片名（分钟数正确），KDoc 已记录。

## 六、结论

时间维度已具备：**任意年份可浏览/切换**、月与年两种视图、空年/空月有明确提示，不再只有 7 天。
