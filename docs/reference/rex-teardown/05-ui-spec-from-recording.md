## 四、页面级要点

1. **发现首页是"轮播驱动"**：hero 占屏 53%，一次只讲一部片；评分聚合（6 源）是信任核心。
2. **继续观看两种形态**：首页横滑小卡（图+进度+看到 xx:xx 叠印）→ 媒体库整行玻璃卡（图+文+来源 logo+进度）。**进度条永远在**，位置随形态换。
3. **媒体库网格页**：顶部右侧"分类/类型"双行玻璃胶囊入口；右下角排序浮钮；返回钮左上浮。三个浮钮都悬在网格上（网格全屏铺底）。
4. **设置全部 iOS 原生样式**（inset grouped + 高行高定制）；长脚注解释每个设置的后果——Rex 的"敢解释"是口碑来源之一。
5. **Pro 付费页**：票券 3D 翻转动画 + 蓝色大按钮（全 app 唯一强 tint 处）。
6. **品牌**：像素风吉祥物（恐龙 + 孵蛋彩蛋，3 次/设备）。轻、好玩、不干扰。

### 6.4 播放态细节

- **锁定态**：全屏只剩左下角**挂锁图标**（~16pt），弹幕/字幕继续渲染；
- **弹幕**：顶部两行区，白字黑描边 ~11.5pt，行距宽；顶栏"弹"圈即总开关；
- **字幕**：底部居中白字 ~15pt 带阴影（Rex 不渲染样式标签，纯文本流）；
- **Live Activity**（sk_0 帧，灵动岛展开）：标题 + ⏸ 按钮直接嵌在岛内 —— Android 对应物是 214 的通知栏（已做）。
