## 4. 边界（不夸大）

1. **背景模糊做不到**：视频层是 SurfaceView 独立合成，Compose 取不到其像素（`PlayerPanelSurface.kt` KDoc 已写明）。
   SenPlayer 卡片内部在彩条底上**无锐边**（确证模糊），我方做不到 —— 这是唯一无法照搬的项。
2. **亮场白字低对比**：白字压在 224–241 的浅玻璃上，标题对比 ≈1.3–1.5:1。
   SenPlayer 在亮底同样如此（218 vs 底 208）。**持平，不是更差**；对比度判据已按用户 2026-11-21 拍板撤销（spec §16.1）。
3. 只在 K40 / 1080p / 横屏测；未测投屏 sheet、状态层在真人片源上的观感。
