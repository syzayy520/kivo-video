# SenPlayer 弹出卡片材质实测（2026-11-21，b6e950ee）

目的：用户判定我方面板质感不如 SenPlayer，要求"能一样就一样"。先量化对方到底做了什么。

## 1. 方法

用 ffmpeg 造 300 s 纯色底（`#1E1E1E` / `#C8D0DC`）与 SMPTE 彩条底，推入
`/sdcard/Movies/Kivo/`，`am start -a VIEW -n com.wuziqi.SenPlayer/.MainActivity`
播放后点顶栏「倍速」图标弹出卡片，截图后用 PIL 直接采样。

## 2. 读数

| 项 | SenPlayer | 我方（`PlayerPanelStyle` v2） |
| --- | --- | --- |
| 深底（#1E1E1E=30）合成色 | **(118,118,118)** | (37,40,45)（底 32 测试片） |
| 浅底（#C8D0DC≈208）合成色 | **(218,226,237)** | — |
| 反解白色透明度 | **≈ 0.40 白** | 底色 #151B23 @ 62–65% |
| 背景模糊 | **有**：彩条底上卡片内竖条边界被完全抹平（内部零锐边） | 无（技术限制见下） |
| 卡片宽 | 604 px ≈ **219.6 dp** | 682 px = 248 dp |
| 圆角 | **≈ 36–38 px ≈ 13.5 dp** | 16 dp |
| 纹理 | 白字压在灰玻璃上，弱描边、圆角柔和 | 白字压深色板，1dp 白 10% 内描边 + 顶边 16% |

证据：`SEN-03/04`（深底）、`SEN-05/06`（浅底）、`SEN-07/08`（彩条，判模糊）、`SEN-09`（设置小卡）、
`CARD-compare-01.png`（并排）。

## 3. 技术边界（我方）

`ui/compose/player/PlayerPanelSurface.kt` 的类注释已写明：视频层是 **SurfaceView，独立合成**，
Compose 拿不到它的像素，`Modifier.blur` 只作用于自身 layer ⇒ **做不出"模糊背后的视频"**。
因此只能照搬"白 ~40% 玻璃 + 圆角 + 弱描边"，**模糊缺失**是最可能被感知到的残余差距。
