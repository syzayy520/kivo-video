## 4. 数据不可得的节（G9：整节隐藏，不造假）

| 节 | 原因 |
| --- | --- |
| 家长指南 | 参照走自有库（带票数），TMDB 无此数据 |
| 多源徽章 | 仅 TMDB 有 `vote_average`；猫眼/时光/豆瓣/番茄/爆米花 无源 |
| 播放资源 / 媒体信息卡 | 需本地媒体库匹配；TMDB 条目无本地文件 → 走**空态块**（与参照同款） |
