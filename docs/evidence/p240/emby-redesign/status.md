# Emby 重设计 · 平板验证

2026-11-09；从 da3a3ec5 及工作区已有网络入口修复继续。用户要求重新设计；不是整页复制某个播放器。参考的已观察范围和文件家族树见 [设计](../../../design/ui/replica/emby-redesign.md)。

## 实现

- 浅灰紫背景、白色分组输入、绿色主按钮，替代旧调试表单。竖屏内容限宽，横屏引导/表单双栏；安全区域、键盘避让和滚动保留。
- 密码显隐、Next/Done、重复提交限制、取消、可重试的简洁错误；响应正文不进入用户提示或异常日志。
- 自适应 2:3 海报墙，圆角裁切、两行片名、省略号与年份；搜索当前列表，按最近添加、中文名称、年份排序，区分空库和无匹配。
- ViewModel 内存保留输入/会话/搜索/排序，密码令牌不写盘。请求回主线程更新；代次校验丢弃取消后的迟到结果；连接任务最多两线程，位图缓存上限24MiB。
- 资源库 Emby 入口文案移除协议术语；不改已认可首页和详情构图。

## 证据

最终包固定仓库签名，覆盖安装 MRR-W29（CFE6R21B12000179，API31，1600×2560 / 400dpi），不卸载、不清数据。`build.log` 为构建记录；`tablet-result.json` 为逐项断言结果；XML/PNG 仅含空表单与合成 demo 输入。真实片单、地址、账号、令牌不归档。

`tablet-result.json` 的13项平板断言通过：密码显隐、合成格式错误、旋转保留输入、真实输入核对、立即返回后32秒不迟到跳转、真实登录60部电影、搜索无匹配/清除、名称排序选择、可见年份实际倒序、旋转保留会话/排序、返回保留表单、重连、恢复设备设置。

完整流程对应 APK 指纹见 `regression-apk.json`。之后仅将库内左上“资源库”文案纠正为“返回”（实际返回连接页）并去除文件尾空行；最终包重新构建覆盖安装，登录/返回/重连复测见 `final-smoke.json`。本阶段不标整个 R4 DONE：空库、全部网络错误类别、手机窄屏/大字与底层播放仍待验。

## 边界与复测

仅拉现有接口的前60部电影，搜索和排序明确限定当前列表；没有分页、剧集、全库搜索或多服务器持久化。缺图暂为中性占位；本轮真实源可正常加载海报，未获得空库服务器来验空库。

取消表示立即结束界面等待并丢弃结果；HttpURLConnection 的阻塞读取仍可能等到自身超时才释放，不能声称底层网络已同步中断。立即返回测试没有单独采样连接中帧，不据此声称已覆盖所有取消竞态。

按用户要求使用平板；K40 没电，手机尺寸/大字号与所有中文输入法手工输入未覆盖。ADB 临时切已有 LatinIME 并逐字段核对，避免将输入法注入错位当账号问题；结束恢复搜狗和自动旋转。

网络播放器本身仍只有视频路径，音频/完整播放/SMB/错误回归未闭环，见[前序阶段](../network-sources/status.md)。不把登录和海报加载当影音播放验收。

复测：固定签名覆盖安装后，从资源库进入 Emby，先以合成格式错误验证显隐/错误/保留输入，再现场填授权服务器并核对输入，登录→搜索无匹配→清除→名称/年份排序→旋转→切服务器→重连。私密 XML 只在内存检查，不存档。`manifest.json` 记录最终源码、证据与 APK 指纹。
