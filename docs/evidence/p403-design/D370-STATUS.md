## 四、本轮顺手修掉的一个真缺陷（原不在台账里）

**token 被服务器吊销后，会话缓存不会失效**（D368 引入会话缓存时留下的洞）：

- 现象：改密/服务器重启清会话后，本地缓存仍把废 token 当有效用到 TTL（15 分钟）到期，
  这期间所有请求 401 ⇒ 用户看到"一直加载失败"。
- 修法：`EmbyClient.cachedBody` 拿到 401 时调 `EmbyAuthCache.invalidateByToken(token)`，
  下次使用自动重新登录（覆盖 details / imageWidths / seasons / episodes / counts / items 全部 GET）。
- 验证：新增 4 个单测（按 token 清除、不误删他人、凭据变更不复用、空 token 安全），
  **全量 115 例 0 失败**。

> 该修复也暴露出一个测试环境问题：`NetDiag.log` 在纯 JVM 单测里会调 `android.util.Log` 抛
> "not mocked"。已改为 `runCatching` 包裹——**日志永远不能把业务搞崩**，这条对生产同样成立。
