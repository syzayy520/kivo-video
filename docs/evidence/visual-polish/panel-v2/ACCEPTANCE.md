## 1. 测量方法（为什么这些数字可信）

视频是 SurfaceView，Compose 侧拿不到像素，所以不做"模糊"验收，只做**合成公式反解**：

```
面板像素 = α × 底色(#151B23) + (1-α) × 视频像素 (+ 高光/描边等叠加项)
```

对同一冻结帧分别截「无面板」「有面板」两帧，在同一坐标读 RGB：

1. **暗场黑边区（视频 = 0）**：面板像素直接等于 `α × 底色`，无需拟合，逐通道可验；
2. **三档联立**：亮/中/暗三组 (视频, 面板) 点求斜率 `1-α` 与截距 `α×底色`；
3. **边缘/分隔**：在同一水平线上跨边缘取 1px 步进的亮度剖面。
