## V6 详情（含本次修复）

### 复现目标
设计意图是「重置行固定卡底，滚动列让位」，滚动区下缘应有 12dp 渐隐。

### 发现（修复前）
- 详情卡结构是 `Box { 滚动 Column(撑满整卡) + 透明重置行压在底部 }`。
- 滚动视口实际到卡片底缘（y=1036），内容从「重置」文字下方穿过：
  - 帧 `probe-c1.png`：行标签文字出现在 y=972..1008，而「重置」文字在 952..986 —— 同一高度叠在一起。
  - 12dp 渐隐挂在卡片底缘（1003..1036），不是在看得见的切口（905）上：`probe-c1.png` 行亮度 236(≤1000)→232(1004)→209(1008) 后才消失。
- `uiautomator` 的 ScrollView bounds 报 905，但像素证据显示内容绘制到 1036 —— 语义边界与绘制边界不一致，本身就是不可信状态。

### 修复
`PlayerDetailCard.kt`：外壳 `Box` → `Column`；滚动列 `weight(1f, fill = false)`，重置行改为列内固定项；滚动列底部 padding 去掉「让位重置行」的额外高度（重置行已在滚动区之外）。

```
Column(卡壳) {
    Column(weight(1f, fill=false) + panelVerticalFade + verticalScroll + padding) { 头 + 行 }
    if (showReset) PlayerResetRow()
}
```

### 修复后证据
- 几何：ScrollView `[1374,226][2320,905]`；重置 `[1374,905][2320,1036]`（132px = 48dp，完整在屏）。
