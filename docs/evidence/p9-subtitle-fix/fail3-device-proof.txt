设备：dd137cf7（2400×1080 横屏）  构建：assembleDebug（含本次修复）
时间：2026-11-19 22:0x–22:2x

一、根因（修复前定性，见 fail3-rootcause-before.txt）
  SubtitlePanelActions.kt: SUBTITLE_PANELS 漏掉入口面板 kind="subtitle"。
  入口面板里两行 tag sub-import / sub-off 由 PlayerPanelForms.subtitleActions() 产生，
  Router → handleSubtitleSelect 先判 `panel in SUBTITLE_PANELS`，不在集合内直接 false，
  随后 writeSelection 对未知 tag 静默 no-op —— 表现为"点了没反应、无 toast、top activity 不变"。
  证据：修复前 4 次点击 touch probe consumed=true，p220-status.log 无任何
  "sub-import: launching SAF picker" 记录。

二、修复
  SubtitlePanelActions.kt: SUBTITLE_PANELS 增加 "subtitle"（入口面板）并写明原因注释。
  （PlayerSubtitleImport.kt 增加 launch/落盘/失败埋点；MpvNative.lastCommandError 记录 JNI 原话。）

四、非字幕 stepper 共享组件回归（PlayerStepperRow 影响面）
  入口：音轨 → 音频延迟（STEP_UNITS 0.05 / 2 位小数，走同一 PlayerStepperRow + 写回链路）
  连点 "增加" 8 次：UI 0.0 s → 0.4 s；kernel 逐 tick：
    audio-delay="0.05" / "0.10" / "0.15" / "0.20" / "0.25" / "0.30" / "0.35" / "0.40"
  点 "重置"：UI 0.0 s，kernel audio-delay="0"。
  结论：共享步进组件在非字幕面板同样逐次生效，无回退。
  UI dump：ui-reg-audio3.xml / ui-reg-audio4.xml / ui-reg-audio5.xml

五、未覆盖 / 风险
  · 导入的字幕轨不随重启自动重挂（会话级；设计未承诺自动恢复，见设计文档 §3.4）。
  · mpv 在片源 EOF 处 sub-add 会失败（内核约束）：若片源已播到结尾再导入，
    toast 会提示"字幕加载失败"，本条与本次缺陷无关，属内核行为。
  · 删除时的"主轨回落"目标是 mpv 默认选择（本片回落到 sid=1 内嵌轨），
    不是回到删除前的内嵌选择（删除前内嵌为 sid=2）。行为正确（无悬空 sid），按实测记录。
